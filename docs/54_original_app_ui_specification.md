# 원본앱 UI/UX 역공학 종합 분석 명세서 (54_original_app_ui_specification.md)

본 문서는 원본 원본앱 바이너리(`original_src/`), 디컴파일 소스 및 심볼(`decompiled_src/`), 언어 및 다이얼로그 리소스(`Language/Korean/`, `DgnLanguage/Korean/`)에서 추출된 MFC/BCGControlBar 윈도우 프레임워크, 리본 메뉴 구성, 4대 메인 폼뷰, 3대 인터랙션 모드, 부재별 다이얼로그 폼, 2D/3D 드로잉 엔진 및 원본 계산서 출력 체계를 총체적으로 역공학 분석한 **원본 데스크톱 애플리케이션 전용 UI/UX 단일 진실 공급원(Ground Truth SSOT)**입니다.

## 1. 원본앱 윈도우 프레임워크 구조

원본 원본앱(`원본앱(Design+.exe)`)은 **MFC (Microsoft Foundation Classes)** 및 **BCGControlBar Pro (v31.2, `BCGCBPRO3120u141.dll`)** 라이브러리를 기반으로 구축된 SDI (Single Document Interface) 엔지니어링 데스크톱 프로그램입니다.

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 원본앱 윈도우 프레임워크 (`CMainFrame` : `CBCGPFrameWnd`)                                      │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. 상단 리본 바 (Ribbon Bar - `CBCGPRibbonBar`): 메인/모드/부재/하중/설정/도구 탭 네비게이션             │
│ 2. 퀵 액세스 툴바 (QAT): 신규, 열기, 저장, 실행취소(Undo), 재실행(Redo), 일괄출력                         │
├───────────────────┬─────────────────────────────────────────────────┬───────────────────────────────────┤
│ 3. 좌측 도킹 바   │ 4. 메인 뷰 에리어 (`CChildFrame` / Multi-View)   │ 5. 우측/중앙 인풋 및 검토 컨트롤  │
│    (WorkTree Dock)│ ┌─────────────────────────────────────────────┐ │ ┌───────────────────────────────┐ │
│   • 부재 탐색 트리│ │ 2D/3D 그래픽 캔버스 (`DPLUS_VDraw.dll`)      │ │ │ 파라메트릭 인풋 폼            │ │
│   • 층별/타입별   │ │  - 단면 배근도 (`CODABeamBase`, `CODABaseCol`)│ │ │  (재료, 단면, 하중, 배근)     │ │
│   • DCR 안전율 배지│ │  - P-M 상관도 및 3D 곡면 다이어그램          │ │ └───────────────────────────────┘ │
│   • 부재 추가/삭제│ │  - 철골 접합부 / 베이스플레이트 2D CAD      │ │ ┌───────────────────────────────┐ │
│                   │ └─────────────────────────────────────────────┘ │ │ 실시간 DCR 및 상태 게이지     │ │
│                   │ ┌─────────────────────────────────────────────┐ │ └───────────────────────────────┘ │
│                   │ │ 4대 메인 폼뷰 전환 (Memb / List / Dwg / Qntt) │ │ ┌───────────────────────────────┐ │
│                   │ └─────────────────────────────────────────────┘ │ │ KDS 실시간 수식 검토 요약로그  │ │
├───────────────────┴─────────────────────────────────────────────────┴───────────────────────────────────┤
│ 6. 하단 상태 표시줄 (Status Bar - `CBCGPRibbonStatusBar`): 현재 단위계, 좌표계, Zoom 배율, 해석 상태     │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1.1. 프레임워크 6대 컴포넌트 상세
1. **`CMainFrame` (`CBCGPFrameWnd`)**: 메인 윈도우 최상위 셸. 리본 바, 도킹 윈도우, 상태 표시줄의 레이아웃 상태를 레지스트리(`HKEY_CURRENT_USER\Software\MIDAS\Design+`)에 직렬화 보존.
2. **리본 바 (`CBCGPRibbonBar`)**: 11개 카테고리 탭, 30개 이상의 기능 패널, 리본 카테고리별 갤러리 및 드롭다운 메뉴 호스팅.
3. **워크트리 도킹 윈도우 (`CBCGPDockingControlBar` / `CWorkTreeBar`)**:
   - `CTreeCtrl` 기반의 계층형 부재 탐색기.
   - 계층 구조: `프로젝트 루트` $\rightarrow$ `층(Story)` $\rightarrow$ `부재 카테고리(RC/Steel/SRC)` $\rightarrow$ `부재 리스트`.
   - 개별 부재 노드에 DCR 안전율 색상 아이콘(초록: OK, 빨강: NG, 회색: 미검토) 표시.
   - 마우스 우클릭 컨텍스트 메뉴: 부재 추가, 부재 복사, 부재 삭제, 단면 이름 변경, 일괄 검토.
4. **메인 뷰 에리어 (`CChildFrame` / Multi-View Host)**:
   - 활성화된 부재 및 선택된 모드에 따라 4대 메인 폼뷰(`CMainFormView*`)를 전환 임베딩.
5. **우측/중앙 인풋 및 검토 컨트롤 (파라메트릭 인풋 폼)**:
   - `CPropertySheet` / `CBCGPPropertySheet` 기반의 탭 다이얼로그.
   - 단면 제원, 배근 규격, 재료 강도, 설계 하중 입력 및 서브 모달 연동.
6. **상태 표시줄 (`CBCGPRibbonStatusBar`)**:
   - 현재 작업 단위계 (`kN, m` / `tonf, m` / `N, mm`), 마우스 좌표계, 뷰 줌 배율, 검토 엔진 해석 상태 표출.

## 3. 원본 4대 메인 폼뷰 (`CMainFormView*`) 구조

원본앱은 선택된 부재와 작업 단계에 따라 4가지 전용 폼뷰 클래스를 동적으로 전환합니다.

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│ 원본 4대 메인 폼뷰 전환 체계                                                       │
├───────────────────────────────────────────────────────────────────────────────────┤
│ [1. CMainFormViewMemb]  단일 부재 상세 설계 및 파라메트릭 캔버스 검토 뷰            │
│ [2. CMainFormViewList]  프로젝트 전체 부재 스프레드시트 일괄 관리 및 DCR 필터링 뷰 │
│ [3. CMainFormViewDraw]  부재별 2D 배근 상세도 및 일람표 CAD 벡터 드로잉 뷰        │
│ [4. CMainFormViewQntt]  콘크리트, 거푸집, 철근, 형강 물량 자동 산출 대시보드 뷰    │
└───────────────────────────────────────────────────────────────────────────────────┘
```

1. **`CMainFormViewMemb` (단면 상세 설계/검토 뷰)**:
   - 선택된 단일 부재의 파라메트릭 입력, 2D 단면 배근도 렌더링, P-M 상관도 및 안전율(DCR) 검토.
   - 단면 치수, 철근 배근, 하중 조건을 조작하면 실시간으로 2D 단면도 및 DCR 게이지가 재계산됨.
2. **`CMainFormViewList` (다중 부재 일괄 관리 뷰)**:
   - 층별/부재별 스프레드시트 그리드 테이블에서 프로젝트 내 모든 부재를 일괄 검토 및 정렬/필터링.
   - 전체 부재의 최대 DCR 부재 검색, NG 부재 일괄 추출, 엑셀 호환 데이터 복사/붙여넣기 지원.
3. **`CMainFormViewDraw` (도면 생성 및 CAD 뷰)**:
   - 완성된 부재의 2D 배근 상세도, 입면도, 단면 배근 일람표 CAD 도면 렌더링.
   - 축척(Scale), 도면 템플릿 선택, 도면층(Layer) 제어 및 DWG/DXF 파일 내보내기.
4. **`CMainFormViewQntt` (물량 산출 및 집계표 뷰)**:
   - 콘크리트 체적($\text{m}^3$), 거푸집 면적($\text{m}^2$), 철근/형강 규격별 중량(ton) 자동 집계.
   - 층별 집계, 부재별 집계, 철근 호칭경별(D10~D32) 물량 집계표 및 Excel 연동 출력.

## 4. 원본 3대 사용자 인터랙션 모드 (Interaction Modes)

원본앱은 설계자의 작업 목적에 맞추어 3가지 상호작용 모드를 제공합니다:

| 모드명 | 원본 C++ 클래스 접미사 | 주요 역할 및 동작 방식 |
|---|---|---|
| **P-Mode** (Design Mode) | `*PModeDlg`<br>(예: `CURBBPModeDlg`, `CFootPModeDlg`) | • **파라메트릭 자동 설계 모드**<br>• 사용자가 단면 외곽 크기, 재료 강도, 설계 부재력을 입력하면 프로그램이 KDS 설계 기준에 부합하는 최적의 철근 배근/형강 규격을 자동 산출 |
| **S-Mode** (Check Mode) | `*SModeDlg`<br>(예: `CURBBSModeDlg`, `CSlabSModeDlg`) | • **단면 안전성 검토 모드**<br>• 사용자가 이미 결정된 단면 치수와 배근 상세(철근 개수/호칭경/단수)를 직접 입력하여 KDS 기준에 따른 안전율(DCR) 및 허용응력/강도를 정밀 검토 |
| **M-Mode** (List/Batch Mode) | `*MListDlg`<br>(예: `CURBBMListDlg`, `CSteelCraneGirderListDlg`) | • **다중 부재 일괄 관리 모드**<br>• 수십~수백 개의 부재를 스프레드시트 그리드에서 한 번에 확인하고 일괄 설계/검토를 실행하여 취약 부재를 신속하게 식별 |

## 5. 부재별 원본 다이얼로그 폼 구조 (`DLG_*.ini` 심층 분석)

원본앱의 부재별 입력 인터페이스는 `Language/Korean/DLG_*.ini` 파일에 정의된 리소스 다이얼로그 구조를 따릅니다.

### 5.1. RC 부재 다이얼로그 (`DLG_DPLUS_RCS.ini`)
* **RC 보 (`IDD_RCS_BEAM_PMODE_DLG`)**:
  - 재료: $f_{ck}$, $f_y$, $f_{ys}$, 경량콘크리트 계수 ($\lambda$)
  - 단면: 직사각형(b, h), T형 보(유효폭 $b_{eff}$, 플랜지 두께 $h_f$), 피복두께 ($d_c$)
  - 배근 유형: 전단면 동일 배근, 단부/중앙부 대칭 배근, 3단면 독립 배근
  - 주철근: 1단/2단 주근 개수 및 호칭경, 철근 순간격 검토
  - 전단철근: 스터럽 호칭경, 다리 수(2-Leg, 4-Leg), 배근 간격(s)
  - 표피/비틀림 철근: 부재 깊이 900mm 초과 시 측면 표피철근 배치 여부
  - 처짐 및 내진: SMF/IMF/OMF 내진 상세, 필로티 보 설정, 균열 제어 환경 조건
* **RC 기둥 (`IDD_RCS_COLUMN_PMODE_DLG`)**:
  - 단면 제원: 직사각형($b \times h$), 원형($D$), 중공 단면
  - 주철근 배열: 사각 배열(X/Y축 대칭, 각 변 분할), 원형 배열(원주 균등 분할)
  - 횡구속 철근: 사각 띠철근(Tie), 원형 띠철근, 나선철근(Spiral) 피치 및 직경
  - P-M 상관도 제어: 실시간 2D P-M 곡선 및 3D P-Mx-My 상호작용 곡면 산출
* **RC 전단벽 (`IDD_RCS_WALL_PMODE_DLG`)**:
  - 벽체 제원: 벽체 두께($t_w$), 벽체 길이($L_w$), 층고($H_w$)
  - 특수경계요소(BE): 경계요소 길이, 경계요소 주철근 및 횡구속 띠철근
  - 웨브 철근: 수직/수평 전단철근 규격 및 간격, 단배근/복배근 선택
* **RC 슬래브 (`IDD_RCS_SLAB_PMODE_DLG`)**:
  - 슬래브 유형: 1방향 슬래브, 2방향 슬래브, 캔틸레버 슬래브
  - 지점 조건: 단순지지, 고정보, 연속보 경간 조건
  - 배근 상세: 단부 상부근, 중앙부 하부근, 온도수축철근
  - 처짐 검토: 최소 두께 규정, 균열 모멘트 및 유효 단면2차모멘트($I_e$) 기반 처짐
* **RC 기초 (`IDD_RCS_FOOT_PMODE_DLG`)**:
  - 기초 제원: 독립 기초(가로, 세로, 두께), 편심 기초, 줄기초, 말뚝 기초
  - 기둥 배치: 기둥 크기, 편심 거리, 작용 축력/모멘트/수평력
  - 지반 조건: 허용 지내력($q_a$), 지반 탄성계수, 침하량 검토
* **RC 옹벽 (`IDD_RCS_RETAINING_WALL_INPUT_DLG`)**:
  - 옹벽 형식: 캔틸레버 역T형, L형, 역L형, 버트레스 옹벽
  - 토압 조건: Coulomb / Rankine 토압, 배면토 경사각, 지하수위, 상재하중
  - 안정성 검토: 활동(Sliding), 전도(Overturning), 지반 지지력, 원호 활동 안정도

### 5.2. Steel 부재 및 접합부 다이얼로그 (`DLG_DPLUS_Steel.ini`)
* **철골 보/기둥 (`IDD_STL_BEAMCOLUMN_INPUT_DLG`)**:
  - 단면 형상: H형강(Rolled/Built-up), 각형강관(HSS/BOX), 원형강관(PIPE), C형강, L형강
  - 비지지길이: $L_b$, 좌굴계수($K_x, K_y$), 모멘트구배계수($C_b$)
  - 강도 검토: 휨항복, 국부좌굴(플랜지/웨브), 횡비틀림좌굴(LTB), 전단항복/전단좌굴
* **철골 접합부 (`IDD_STL_BOLTCONNECTION_INPUT_DLG`, `IDD_STL_WELDING_INPUT_DLG`)**:
  - 볼트 접합: 고력볼트(F10T, F8T, A325, A490), 마찰이음/지압이음, 연단거리/피치
  - 용접 접합: 모살(Fillet) 용접, 맞댐(CJP/PJP) 용접, 유효 목두께
* **주각부 베이스플레이트 (`IDD_STL_USBP_PMODE_DLG`)**:
  - 베이스플레이트: 강판 크기($B \times N$), 강판 두께($t_p$), 강재 재질
  - 앵커볼트: 직경, 개수, 매입 깊이, 인장/전단 파괴 및 콘크리트 프라이아웃 검토
  - 콘크리트 지압: 페디스탈 지압 강도 및 무수축 모르타르 그라우트 검토

### 5.3. 합성(SRC) 및 기타 부재 다이얼로그 (`DLG_DPLUS_SRC.ini`)
* **SRC 기둥**: 매입형 H형강 + RC 복합 단면, 충전형 강관 콘크리트(CFT)
* **합성보**: 데크플레이트 골 방향(순방향/직각방향), 스터드 볼트(Stud Shear Connector) 전단연결재 검토

## 6. 원본 2D/3D 드로잉 엔진 분석 (`DPLUS_VDraw.dll`)

원본앱은 벡터 기반 드로잉 엔진인 `DPLUS_VDraw.dll`을 통해 고품질 2D 단면도 및 철근 상세도를 렌더링합니다.

* **핵심 드로잉 클래스 체계**:
  - `CODABeamBase`: RC 보 단면 및 종방향 배근도 드로잉 엔진
  - `CODABaseColumn`: RC 기둥 단면, 주근 배치원, 띠철근 후크 드로잉
  - `CODABaseFooting`: 기초 평면도, 단면 배근도, 말뚝 배치도 드로잉
  - `CODABaseWall`: 전단벽 단면도, 단부 경계요소 보강 상세 드로잉
  - `CODABaseSteel`: H형강, 접합부 볼트 구멍, 가셋플레이트, 용접 기호 드로잉
* **주요 렌더링 메소드 파이프라인**:
  - `DrawSect`, `DrawFrameBody`: 부재 콘크리트 외곽선 폴리라인 생성 및 음영 채우기(Hatch)
  - `DrawStirrup`: 피복두께 오프셋 계산, 모서리 곡률(Bend Radius), 135도 내진 갈고리(Hook) 기하 산출
  - `DrawMainBar`: 주철근 기하학적 중심 좌표($x, y$) 산출, 솔리드 원형 심볼 및 호칭경 스케일 렌더링
  - `DrawTxtInfo`, `DrawFrameHeadText`: 치수선($b, h, d$), 인출선(Leader Line), 배근 태그 텍스트 배치
* **뷰포트 인터랙션 메커니즘**:
  - 마우스 휠을 이용한 실시간 Zoom In/Out
  - 마우스 드래그를 이용한 화면 이동(Pan)
  - 'Fit View' 단축키 및 더블클릭을 통한 캔버스 영역 자동 맞춤
  - 횡단면(Section)과 종단면(Elevation) 창 분할 연동 표시

## 7. 원본 계산서 생성 체계 (`DgnReportBase.ini`, `GENDgnReportKR.ini`)

원본앱의 계산서 출력 엔진은 `DgnReportBase.ini` 및 `GENDgnReportKR.ini`의 다국어 템플릿과 섹션 구성을 기반으로 동작합니다.

* **표준 계산서 목차 및 5단계 구성**:
  1. **일반 사항 (General Information)**:
     - 프로젝트명, 부재명, 작성자, 검토자, 적용 설계 기준(KDS / ACI / AISC), 단위계
  2. **재질 및 단면 (Material & Section Properties)**:
     - 콘크리트 강도($f_{ck}$), 철근 항복강도($f_y, f_{ys}$), 탄성계수($E_c, E_s$)
     - 단면 치수 제원($b, h, d, d'$), 단면적($A_g$), 단면2차모멘트($I_g$), 2D 단면 배근 형상도
  3. **설계 하중 (Design Loads & Forces)**:
     - 설계 부재력 조합 ($P_u, M_u, V_u, T_u$)
  4. **단면 검토 (Section Strength & Serviceability Checks)**:
     - **휨 강도 검토**: 설계 휨강도($\phi M_n$), 계수 휨모멘트($M_u$), 휨 DCR, 연성 조건(최순인장변형률 $\epsilon_t$)
     - **전단 강도 검토**: 콘크리트 전단강도($V_c$), 전단철근 전단강도($V_s$), 전단 DCR, 최소 전단철근비, 최대 간격
     - **처짐 검토**: 유효 단면2차모멘트($I_e$), 즉시 처짐, 장기 추가 처짐, 허용 처짐 기준 대조
     - **균열 검토**: 사용 하중 휨모멘트, 철근 인장응력($f_s$), 허용 균열폭 또는 간격 기준 대조
  5. **종합 판정 (Final Summary)**:
     - 원본앱 특유의 결과 지시 화살표 표기:
       * `IDS_DGNREPORTBASE_ARROW_OK` $\rightarrow$ `"  →  O.K"`
       * `IDS_DGNREPORTBASE_ARROW_NG` $\rightarrow$ `"  →  N.G"`
     - 지배 DCR(Governing DCR) 산출 및 최종 안전성 합격 여부 마킹

## 8. 원본앱 특유의 사용자 경험(UX) 및 인터랙션 특성

데스크톱 환경에서 구조 엔지니어가 경험했던 원본앱의 핵심 UX 패턴입니다:

1. **단면 제원 및 배근의 즉시 피드백**:
   - 입력란에서 포커스가 벗어나거나 엔터 키를 누르는 즉시 좌측/상단 캔버스에 수정된 배근 형상이 리드로잉됨.
2. **배근 유형(Arrange Type) 라디오 선택 체계**:
   - RC 보의 경우 '전단면 동일 배근', '양단부 동일 / 중앙부 분리 배근', 'i단 / m단 / j단 3단면 분리 배근' 라디오 버튼에 따라 하단 입력 테이블의 행들이 동적으로 활성화/비활성화됨.
3. **철근 순간격 경고**:
   - 주철근 개수가 과다하여 굵은 골재 최대 치수 또는 규정 순간격 미달 시 입력창 옆에 붉은색 경고 텍스트 표시.
4. **서브 대화창(`...`) 모달 팝업**:
   - T형보 유효폭 계산기, 장주 편심거리 계산기, 비지지길이 계산기 등 복잡한 수치 산정이 필요한 항목은 인풋 박스 옆의 `...` 버튼을 눌러 보조 팝업 다이얼로그를 호출하여 결과를 본체 입력창에 적용.
5. **계산서 출력 옵션 제어 (`DgnReportOptionDlg`)**:
   - 요약 계산서(1~2페이지) vs 상세 계산서(수식 및 전개 과정 전수 포함) 라디오 선택.
   - 사용자 입력 데이터 테이블 포함 여부 체크박스.
   - Word(.doc, .rtf) 내보내기, Excel(.xls) 내보내기, 인쇄 미리보기 지원.

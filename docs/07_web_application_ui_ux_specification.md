# [PART 1] AltDP_3rd 모던 웹 UI/UX 아키텍처 (우리 앱 우선)

## 1. 개요 및 4대 핵심 UX 설계 철학 (Design Philosophy)

AltDP_3rd는 건축 구조 엔지니어가 4대 카테고리(RC, Steel, SRC/PC, Misc/RFM) 54개 단위부재의 단면 내력 검토 및 최적 배근 설계를 웹 브라우저에서 쾌속으로 수행할 수 있도록 설계된 **Zero-Build 4분할(4-Pane) 반응형 올인원 웹 애플리케이션**입니다.

### 🌟 4대 핵심 UX 원칙
1. **무결한 시인성 (Flawless Legibility & Fixed White Sheet)**:
   - 작업 인터페이스는 **다크 테마(Dark Mode)**와 **라이트 테마(Light Mode)**를 자유롭게 전환.
   - 단, **KDS 구조계산서 영역은 실제 A4 인쇄물과의 1:1 완벽 호환을 위해 테마와 무관하게 언제나 순백색(`#ffffff`) 배경과 고대비 텍스트(`#111827`)**를 고정 유지.
2. **독립 4분할 워크스페이스 (Isolated 4-Split Layout)**:
   - 탐색기(사이드바), 부재 매니저(Pane 1), 파라메트릭 폼(Pane 2), 세로 적층형 그래픽 뷰포트(Pane 3), KDS 계산서(Pane 4)가 드래그 시 서로 연쇄 간섭 없이 독립적으로 크기 조절.
3. **스마트 자동 숨김 & 즐겨찾기 고정 인터랙션 (Smart Collapsible Sidebar & Favorites)**:
   - 8대 카테고리 Pills 탭 필터와 상시 고정 **[⭐ 즐겨찾기]** 시스템을 제공하며, 집중 모드 시 3초 무조작 및 마우스 이탈 시 사이드바가 자동으로 접히고, 고정핀(📌)을 꽂으면 상시 고정 유지 (`Ctrl + B` 토글 지원).
4. **3버튼 통합 액션 파이프라인 (Optimized Action Pipeline)**:
   - **[💾 적용 (Apply)]**, **[⚡ 검토 (Check)]**, **[✨ 설계 (Design)]** 단일화 파이프라인 제공 (검토/설계 시 항상 적용 선행 실행).

## 2. 상단 마스터 툴바 (Top Master Toolbar)

상단 툴바는 전역 설정 및 빠른 도구 기능을 제공합니다:

1. **브랜드 & 기준 배지**:
   - `AltDP Member Designer` 로고 + `KDS 2022 / KDS 14 20 00 / 14 31 00` 기준 태그.
2. **사이드바 토글 버튼 (Ctrl+B)**:
   - 좌측 네비게이터를 즉시 열고 닫는 단축키 및 토글 버튼.
3. **초고속 모듈 검색바 (Ctrl+K, `#quick-search`)**:
   - 54종 단위부재(보, 기둥, 전단벽, 슬래브, 기초, H형강, 접합부 등) 퍼지 검색 및 즉시 활성화.
4. **4대 단위계 실시간 전환기 (`unit_manager.js`)**:
   - `SI`: $\text{kN, mm, MPa, kN}\cdot\text{m}$ (기본값)
   - `SI_M`: $\text{kN, m, kPa, kN}\cdot\text{m}$
   - `MKS`: $\text{tonf, m, kgf/cm}^2\text{, tonf}\cdot\text{m}$
   - `US`: $\text{kip, in, ksi, ft}\cdot\text{kip}$
   - *단위계 변경 시 입력폼 값, 캔버스 치수, 계산서 수식이 0.01초 내 자동 변환 및 유효숫자 포맷팅.*
5. **테마 & 레이아웃 관리**:
   - **다크/라이트 테마 (🌙/☀️)**: 고대비 엔지니어링 테마 토글 (`theme_manager.js`).
   - **레이아웃 기본값 저장 (`📌 Save Layout`)**: 분할 비율 및 사이드바 상태를 `localStorage`에 영속화.
   - **레이아웃 초기화 (`🔄 Reset Layout`)**: 기본 황금비 분할로 원클릭 복원.

## 3. 계층형 모듈 탐색기 및 스마트 사이드바 (Left Sidebar: `#sidebar-nav`)

스마트 사이드바는 번잡한 상단 검색창/칩을 덜어내고 사이드바 내에 **초고접근성 3중 필터 네비게이션**과 즐겨찾기 시스템을 제공합니다:

### 3.1. 8대 카테고리 Pills 탭 필터 (Category Pills)
* **[전체보기 (ALL)]**: 61종 전체 모듈 전개.
* **[즐겨찾기 (⭐ Favorites)]**: 사용자가 즐겨찾기 등록한 모듈 및 활성 부재만 최상단 집중 표시.
* **[RC 콘크리트]**: 보, 기둥, 전단벽, 슬래브, 기초, 옹벽, 지하외벽, 앵커볼트, 코벨/브라켓.
* **[STEEL 강구조]**: 철골보, 철골기둥, 가새, 트러스, 크레인거더, 접합부 5종, 베이스플레이트.
* **[SRC / PC]**: SRC 기둥/보, CFT 기둥, 프리캐스트 보/슬래브, 더블티, 할로우코어.
* **[ALU 알루미늄]**: 알루미늄 보/기둥, 커튼월 멀리온, 루버 프레임.
* **[RFM 보강]**: CFRP 탄소섬유판/시트 보강, 강판 접착 보강, 콘크리트 단면증설.
* **[기초 / 특수]**: 독립/복합/줄기초, 말뚝기초, 평판 FEM 매트기초.

### 3.2. 즐겨찾기(Favorites ⭐) 상시 고정 시스템
* 각 모듈 및 부재명 우측에 별표 아이콘(`☆`/`★`) 제공.
* 클릭 시 `localStorage`에 영속화되며 사이드바 최상단 `[⭐ 즐겨찾기]` 그룹에 상시 고정되어 실무 빈출 부재(RC보, 기둥, H형강보 등)로 1클릭 즉시 전환.

### 3.3. 3단계 계층 WorkTree 및 DCR 2단계(OK/NG) 글자 표기
* **Level 1 (대분류)** $\rightarrow$ **Level 2 (단위 모듈 & 등록 부재 수 `(N)`)** $\rightarrow$ **Level 3 (개별 등록 부재 `1F-B1` 등)**.
* **DCR 상태 2단계 텍스트 표기 (칩/배경색 제거, 폰트 컬러로만 표기)**:
  - **OK (`DCR ≤ 1.000`)**: **녹색 글자 (`OK`)**로만 깔끔하게 표기.
  - **NG (`DCR > 1.000`)**: **빨간색 글자 (`NG`)**로만 표기. 클릭 시 해당 부재로 즉시 전환되고 4열 계산서의 불합격 수식 위치로 자동 스크롤.
* **스마트 자동 숨김 및 고정핀 (📌)**:
  - 집중 모드 시 3초 무조작 및 마우스 이탈 시 슬라이드 수축 (`Ctrl + B` 단축키 토글 지원).
  - 고정핀(📌)을 클릭하면 워크스페이스 패널로 상시 고정.
* **프로젝트 파일 입출력 (Project I/O)**:
  - `💾 저장 (Export)`: 프로젝트 내 모든 부재 데이터를 단일 `.json` 파일로 다운로드 (`Ctrl + S`).
  - `📂 불러오기 (Import)`: 저장된 JSON 파일을 로드하여 다중 부재 상태 완벽 복원.

## 4. 4분할 작업 영역 상세 명세 (4-Pillars)

### 4.1. Pane 1: 다중 부재 매니저 (Top-Left: `#pane-member-list`)
* **컴포넌트**: `member_manager.js`
* **위치 및 크기**: Left-Sub 패널 상단 (높이: 80px ~ 400px 상하 수직 리사이저 `resizer-left-v`로 가변 조절).
* **주요 기능**:
  - **부재 인스턴스 CRUD**: `[+ 추가 (Add)]`, `[복제 (Duplicate)]`, `[삭제 (Delete)]` 툴바 액션.
  - **인라인 부재명 변경**: 더블클릭 또는 인라인 편집으로 `1F-B1`, `Roof-G2` 등 신속 변경.
  - **실시간 요약 스프레드시트 테이블**:
    | 부재명 | 단면 치수 ($b \times h$) | 주요 배근 / 형강 규격 | 소요력 ($M_u, V_u$) | DCR 상태 (글자 표기) |
    |:---:|:---:|:---:|:---:|:---:|
    | **1F-B1** | $400 \times 600$ | 상 4-D25, 하 4-D25 | $210 \text{ kN}\cdot\text{m}$ | **0.807 OK** (녹색 글자) |
    | **1F-B2** | $500 \times 700$ | 상 6-D25, 하 6-D25 | $450 \text{ kN}\cdot\text{m}$ | **1.052 NG** (빨간색 글자) |
  - 행 클릭 시 0.01초 내 해당 부재의 입력폼, 그래픽 뷰, 계산서가 즉시 동기화 전환.

### 4.2. Pane 2: 파라메트릭 사용자 입력부 (Bottom-Left: `#pane-input-form`)
* **컴포넌트**: `form_generator.js`, `form_combobox.js`, `modal_manager.js`
* **위치**: Left-Sub 패널 하단.
* **주요 구성**:
  - **2단 적층형 헤더 (Vertical Stack Header)**:
    - 1행: `⚙️ 사용자 입력부 (Input)` 타이틀 바 및 활성 부재 뱃지(`[1F-B1]`).
    - 2행: 사용자 입력부 가로 폭(100%)을 사용하는 전용 모듈 경로 배너 (`RC › 보 (Beam) › 직사각형 보`).
  - **모듈 주도형 가변 서브탭 표준 아키텍처**:
    - 사용자 입력부는 **통일된 다크/라이트 테마와 정밀 엔지니어링 UX를 공유**하되, **상부 서브탭의 개수(1~5개)와 명칭, 입력받는 데이터 제원 및 형태는 원본앱(`DLG_*.ini`)으로부터 도출하여 각 설계 모듈에서 직접 정의/주입**.
    - RC 보 플래그십 예시:
      1. **[단면 / 재료 탭]**: 단면 형상(직사각형/T형), 단면 치수($b, h, L$), KS 표준 강종($f_{ck}, f_y, f_{yt}$), 피복두께.
      2. **[철근 배근 탭]**: 단부( i ), 중앙( m ), 단부( j ) 3대 위치별 상하부 다단 주철근, 스터럽 직경/간격/다리수, 표피철근.

  - 모달 팝업을 통해 프로젝트명, 회사명(풀네임/약칭), 부재 태그, 검토자/승인자 서명란, 검토 일자 및 회사 로고 이미지를 실시간 주입.

  - **인쇄 (`[🖨️ 인쇄 (Print)]`)**: 브라우저 표준 A4 인쇄 파이프라인 (`window.print()`).
  - **엑셀 내보내기 (`[📊 Excel 내보내기]`)**: 현재 기본 계산서 내보내기 기능이 연동되어 있으며, 향후 셀 병합, KDS 표준 스타일 서식, 고해상도 수식 이미지 탑재 등 관공서 제출용 정밀 계산서 양식으로 **추후 고도화 예정**.

## 16. 원본앱 4대 폼뷰 및 3대 인터랙션 모드 1:1 웹 구현 매핑

원본 원본앱의 데스크톱 SDI 환경을 AltDP_3rd의 반응형 웹 환경으로 1:1 완벽 이식하기 위한 구조적 매핑 사양입니다:

### 16.1. 4대 메인 폼뷰 1:1 웹 구현 매핑
1. **Memb View (`CMainFormViewMemb`) $\rightarrow$ 독립 4분할 워크스페이스**:
   - 단일 부재 정밀 4분할 워크스페이스 (속성 그리드 ↔ 2D 단면 배근도 ↔ P-M 상관곡선/DCR ↔ KDS 실시간 요약서).
   - `pane-member-list`, `pane-input-form`, `pane-graphic-view`, `pane-right-report`의 4열 동시 구동.
2. **List View (`CMainFormViewList`) $\rightarrow$ 상단 [부재 목록] 뷰 (`batch_grid.js`)**:
   - 다중 부재 일괄 스프레드시트 검토 뷰 (층별/부재별 트리 네비게이터, Excel형 그리드, 원클릭 일괄 DCR 히트맵).
3. **Draw View (`CMainFormViewDraw`) $\rightarrow$ 상단 [도면] CAD 뷰 (`draw_cad.js`)**:
   - 2D 배근 상세도 및 일람표 CAD 뷰어 (보/기둥 단면/입면 벡터 드로잉, 스케줄 테이블, DXF/SVG 다운로드).
4. **Qntt View (`CMainFormViewQntt`) $\rightarrow$ 상단 [물량] 대시보드 뷰 (`qntt_summary.js`)**:
   - 콘크리트/거푸집/철근/강재 자동 물량 산출 대시보드 (D10~D32 직경별 물량, 형강 중량, 도넛 차트 및 Excel 내보내기).

### 16.2. 3대 인터랙션 모드 1:1 웹 파이프라인 매핑
1. **P-Mode (Parametric Auto-Design Mode) $\rightarrow$ [✨ 설계 (Design)] 버튼 파이프라인**:
   - 설계 단면 가정 및 KDS 강도설계법/허용응력설계법에 따른 최적 철근 배근 및 형강 규격 자동 제안 (`auto_designer.js`).
2. **S-Mode (Section Check Mode) $\rightarrow$ [⚡ 검토 (Check)] 버튼 파이프라인**:
   - 기 배근된 단면 및 단면 제원에 대해 모멘트/전단/축력/비틀림 DCR을 즉각 해석/검토하는 엔지니어링 검토 모드.
3. **M-Mode (Member Management Mode) $\rightarrow$ 사이드바 및 다중 부재 매니저 (`member_manager.js`)**:
   - 부재 태그, 그룹핑, 층(Story) 배치, 하중 케이스 연계 등 구조 모델 메타데이터를 통합 관리하는 모드.

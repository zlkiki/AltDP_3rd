# 요구사항 11-3: 전 도메인 회귀테스트 및 0.1% 무결성 검증

## 1. 개요 및 목적 (Overview & Goals)

### 1.1. 배경 및 목적
* AltDP_3rd 프로젝트의 11개 마일스톤에 걸쳐 구축된 **전체 구조설계 엔진, 단면 DB 파서, 비선형 수치 솔버, REST API 라우트, 웹 UI/UX 및 캔버스 렌더러, A4 구조계산서 및 오피스 익스포트 파이프라인**에 대한 전수 회귀 테스트 및 최종 무결성 검증을 완결합니다.
* Ghidra 추출 47,110개 심볼 및 47개 핵심 C 소스 알고리즘, KDS 국가건설기준(`kcsc2md`) 예제집 대비 **0.1% 미만 오차 무결성**을 최종 확정합니다.
* 3대 초고속 Pytest 스위트(엔진, API, UI)와 E2E 통합 시나리오 테스트(`tests/e2e/test_full_pipeline.py`)를 100% 통과시키며, 전체 테스트 실행 시간을 1.5초 이내로 유지합니다.
* 전체 프로젝트 마스터플랜(`docs/12_full_feature_porting_master_plan.md`)의 모든 요구사항 상태를 완료(100%)로 승격하고 최종 산출물 무결성을 확정합니다.

### 1.2. 참조 Ground Truth 및 검증 스위트
* **3대 Pytest 스위트**:
  - `pytest tests/engine/` (~0.5s) : 수치해석, 파이버 단면, RC 6종, 철골 6종, 특수 3종(SRC/ALU/RFM) 내력 및 사용성 단위 테스트
  - `pytest tests/api/` (~0.5s) : RC, Steel, DB, Report, Special 전체 REST API 엔드포인트 및 스키마 테스트
  - `pytest tests/ui/` (~0.5s) : Jinja2 템플릿, HTML DOM 구조, 캔버스 좌표 매핑 및 P-M 포인트 연산 테스트
  - `pytest tests/report/` : A4 구조계산서 Jinja2-LaTeX 렌더링 및 Excel 익스포트 테스트
  - `pytest tests/e2e/` : 단면 선택 $\rightarrow$ 하중 입력 $\rightarrow$ 해석/설계 $\rightarrow$ 캔버스/차트 $\rightarrow$ 계산서 출력 E2E 파이프라인 테스트
* **전체 실행**: `pytest` (전 스위트 100% PASS, 0.1% 오차 무결성)

## 2. 세부 검증 시나리오 및 E2E 파이프라인

### 2.1. E2E 통합 테스트 파이프라인 (`tests/e2e/test_full_pipeline.py`)
1. **RC 부재 풀 파이프라인 검증**:
   - RC 보 / 기둥 / 전단벽 / 슬래브 / 기초 / 옹벽 입력 $\rightarrow$ API 호출 $\rightarrow$ 휨/전단/사용성 DCR 검증 $\rightarrow$ HTML/A4 계산서 렌더링.
2. **철골 및 접합부 풀 파이프라인 검증**:
   - KS H형강 DB 조회 $\rightarrow$ 보/기둥 좌굴 및 휨전단 DCR 검증 $\rightarrow$ 볼트/엔드플레이트/베이스플레이트 접합부 검증 $\rightarrow$ Excel/계산서 생성.
3. **특수 구조 및 보수보강 풀 파이프라인 검증**:
   - CFT/SRC 기둥 소성압축강도 $\rightarrow$ 알루미늄 보 $\rightarrow$ CFRP/강판 보수보강 내력 증진도 산정 및 통합 출력.
4. **웹 대시보드 및 정적 파일 무결성 검증**:
   - FastAPI `/`, `/static/...`, `/health` 서빙 및 JSON 스키마 유효성.

### 2.2. 성능 및 속도 보증 (Speed SLA)
* 전체 140+ 단위/통합 테스트 스위트의 실행 시간이 **1.5초 이내**로 완결되는지 확인.

# [요구사항19-5] 고급 특화기능(FEM 도면CAD 물량 PBD Gen) UI 연동 완성

## 1. 개요 및 목적
* AltDP_3rd에만 존재하는 독보적인 고급 엔지니어링 기능(2D FEM 평판/기초 솔버, 3D P-M 상관곡면 인터랙티브 차트, 2D 배근상세도 CAD DXF 생성기, KDS 표준 물량산출 대시보드, MIDAS Gen .mgt 텍스트 모델 연동기)을 이식된 AltDP_2nd의 4분할 UI에 심리스하게 통합합니다.

---

## 2. 세부 개발 작업 명세

### 2.1. 2D FEM 평판/기초/외벽/접촉 솔버 시각화 연동
* 타겟 모듈: 매트기초, 지하외벽 2방향 판휨, 개구부 슬래브, 베이스플레이트 비선형 접촉.
* 연동 방식:
  - 검토 완료 시 Pane 3(Graphic View)에 DKMQ 4절점 쉘 메쉬망 및 응력(Von-Mises/휨모멘트) 등고선 오버레이 렌더링.
  - 지반 비선형 인장분리 접지압 분포도 및 반력 테이블을 Pane 4(계산서)에 자동 바인딩.

### 2.2. 3D P-M 상관곡면 인터랙티브 차트 연동
* 타겟 모듈: RC 기둥(`rc/column/*`), 철골 기둥(`steel/member/column`).
* 연동 방식:
  - 캔버스 툴바에 `[📈 3D P-M]` 토글 버튼 제공.
  - 클릭 시 2D 배근 단면도 위에 회전 가능한 3D $P-M_x-M_y$ 상관곡면 및 현재 하중점 $(P_u, M_{ux}, M_{uy})$ 3차원 위치 표출.

### 2.3. 2D CAD 배근상세도 DXF 원클릭 내보내기
* 상단 마스터 툴바 및 Pane 4 계산서 하단에 `[📐 CAD 도면 (DXF)]` 버튼 추가.
* 클릭 시 `src/engine/dxf/cad_exporter.py`를 호출하여 현재 활성 부재의 단면/배근 상세도가 담긴 `.dxf` 파일을 즉시 다운로드.

### 2.4. KDS 표준 물량산출 대시보드 및 Excel 내보내기
* 상단 툴바에 `[📊 물량 산출]` 버튼 추가.
* 클릭 시 모달 팝업으로 프로젝트 등록 부재 전체의 콘크리트($\text{m}^3$), 거푸집($\text{m}^2$), 철근 규격별 중량($\text{ton}$), 구조용 강재 중량 집계표 표출 및 다중시트 Excel(`.xlsx`) 다운로드 연동.

### 2.5. MIDAS Gen 3D 모델(.mgt) 임포트 및 LCB 자동 선별
* 좌측 사이드바 프로젝트 관리부에 `[📂 Gen 임포트]` 버튼 배치.
* `.mgt` 텍스트 스크립트 및 부재력 DB 파일 로드 시, 최악하중 Governing LCB를 자동 선별하여 다중 부재 리스트(Pane 1)에 일괄 자동 등록.

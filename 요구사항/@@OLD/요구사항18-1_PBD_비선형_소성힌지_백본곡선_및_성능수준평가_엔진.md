# 요구사항 18-1: PBD 비선형 소성힌지 백본곡선 및 성능수준 평가 엔진 (Phase 18-1)

## 1. 개요 및 목적 (Overview & Goals)

### 1.1. 배경 및 목적
* Midas Design+ 원본의 **성능기반 내진설계 모듈(`IDS_RIBBON_BARR_PBD`)**을 웹 아키텍처로 구현합니다.
* KDS 41 17 00(건축물 내진설계기준) 및 ASCE 41-17 규준에 따라, 철근콘크리트(보, 기둥, 전단벽) 및 철골(보, 기둥, 가새) 부재의 **비선형 모멘트-회전각($M-\theta$) 및 전단-변형률($V-\gamma$) 소성힌지(Plastic Hinge) 백본 곡선(Backbone Curve)**을 자동 생성하고 목표 성능수준을 판정합니다.

---

## 2. 세부 개발 명세

### 2.1. RC 부재 소성힌지 모델 (`src/engine/pbd/hinge_rc.py`)
* **ASCE 41-17 / KDS 41 17 00 매개변수 산정**:
  - 항복 모멘트($M_y$), 소성 회전각 한계값($a, b, c$), 잔류 강도비($c/M_y$).
  - 기둥 축력비($P / A_g f_{ck}$) 및 전단 철근비($\rho_w$)에 따른 연성/취성 거동 모드 분기.
  - 전단벽 휨 힌지 및 면내 전단 힌지 백본 특성치 산정.

### 2.2. 철골 부재 소성힌지 모델 (`src/engine/pbd/hinge_steel.py`)
* AISC 341 / ASCE 41-17 기반 폭두께비(Compactness) 및 횡지지 길이에 따른 힌지 매개변수 산정.
* 인장/압축 가새의 좌굴 후 강도 저하 및 이력 백본 곡선 생성.

### 2.3. 백본 곡선 생성 및 한계상태 판정 (`src/engine/pbd/backbone_curve.py`)
* **다선형 백본 곡선 (Trilinear / Tetralinear Curve)**:
  - $(0,0) \rightarrow (\theta_y, M_y) \rightarrow (\theta_u, M_u) \rightarrow (\theta_r, M_r) \rightarrow (\theta_f, 0)$ 좌표열 생성.
* **3대 성능수준 판정**:
  - **IO (Immediate Occupancy, 즉시거주)**: 탄성 한계 직후 소성변형 영역
  - **LS (Life Safety, 인명안전)**: 주요 구조적 손상 허용 수준
  - **CP (Collapse Prevention, 붕괴방지)**: 잔류 저항력 유지 한계점

## 3. 데이터 스키마 (Pydantic DTO)

```python
from pydantic import BaseModel
from typing import List

class BackbonePoint(BaseModel):
    theta_rad: float  # 회전각 (rad)
    moment_knm: float # 휨모멘트 (kN*m)

class HingePerformance(BaseModel):
    member_id: int
    member_type: str
    my_knm: float
    theta_y_rad: float
    io_limit_rad: float
    ls_limit_rad: float
    cp_limit_rad: float
    backbone_curve: List[BackbonePoint]
    performance_level: str  # "IO", "LS", "CP", "COLLAPSE"
```

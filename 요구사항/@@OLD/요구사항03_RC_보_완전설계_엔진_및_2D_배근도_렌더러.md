# 요구사항 03: RC 보(Beam) 완전설계 엔진 및 2D 배근도 렌더러

## 1. 개요 및 목적 (Overview & Goals)

### 1.1. 배경
철근콘크리트(RC) 보(Beam)는 건축 구조물의 대표적인 휨-전단 부재로서, 단철근/복철근 휨 설계, 전단 및 비틀림 철근 배근, 그리고 처짐과 균열에 대한 사용성 검토를 포괄적으로 수행해야 합니다. Midas Design+의 `CRCSCodeCheck::CHK_BBBE` 계열 함수는 이러한 휨, 전단, 비틀림, 처짐 알고리즘을 C++로 구현하고 있습니다.

### 1.2. 목적
1. `decompiled_src/core_routines/rc/`의 `rc__CHK_BBBE_*.c` 소스코드를 기반으로 KDS 14 20 20(휨), KDS 14 20 22(전단/비틀림), KDS 14 20 30(사용성) 기준을 100% 만족하는 순수 Python RC 보 설계 엔진(`src/engine/rc/beam.py`) 구현.
2. 단면 치수($b, h$), 주철근($A_s, A_s'$), 전단 스터럽($A_v$), 비틀림 종방향 철근($A_l$)을 입력받아 강도 검토(DCR) 및 자동 최적 배근 알고리즘 구축.
3. 계산된 배근 정보를 시각화하는 Canvas/SVG 기반 2D 배근도 렌더러(`src/web/static/js/renderer2d.js`)를 구축하여 직관적인 부재 단면 시각화 제공.

## 2. KDS 국가건설기준 및 공학 수학 공식

### 2.1. 휨 한계상태 설계 (KDS 14 20 20)
* **단면 유효높이**: $d = h - d_c$, 압축철근 유효깊이 $d'$
* **압축응력블록 깊이 ($a$) 및 중립축 ($c$)**:
  - 단철근 보: $a = \frac{A_s f_y}{\alpha_1 f_{ck} b}, \quad c = \frac{a}{\beta_1}$
  - 복철근 보: 압축철근 항복 판정 ($\epsilon_s' = \epsilon_{cu} \frac{c - d'}{c} \ge \epsilon_y$)
    - 항복 시: $a = \frac{A_s f_y - A_s' f_y}{\alpha_1 f_{ck} b}$
    - 미항복 시: $c$에 대한 2차 방정식 해석
* **설계 휨강도 ($\phi M_n$)**:
  $$\phi M_n = \phi \left[ (A_s f_y - A_s' f_s')\left(d - \frac{a}{2}\right) + A_s' f_s' (d - d') \right]$$
* **최소 철근량 ($A_{s,min}$)**:
  $$A_{s,min} = \max\left( \frac{0.25\sqrt{f_{ck}}}{f_y} b_w d, \; \frac{1.4}{f_y} b_w d \right)$$
* **최대 철근비 및 연성 조건**: $\epsilon_t \ge 0.004$ (인장지배 $\epsilon_t \ge 0.005$ 권장)

### 2.2. 전단 및 비틀림 설계 (KDS 14 20 22)
* **콘크리트 부담 전단강도 ($V_c$)**:
  $$V_c = \frac{1}{6}\lambda \sqrt{f_{ck}} b_w d$$
* **전단철근 부담 전단강도 ($V_s$)**:
  $$V_s = \frac{A_v f_{yt} d}{s} \le \frac{2}{3}\sqrt{f_{ck}} b_w d$$
* **비틀림 균열모멘트 ($T_{cr}$) 및 비틀림 검토 한계**:
  $$T_{cr} = \frac{1}{3}\lambda \sqrt{f_{ck}} \left(\frac{A_{cp}^2}{p_{cp}}\right), \quad T_u \le \phi \frac{T_{cr}}{4} \implies \text{비틀림 무시 가능}$$
* **비틀림-전단 합성 단면적 상한 검토**:
  $$\sqrt{\left(\frac{V_u}{b_w d}\right)^2 + \left(\frac{T_u p_h}{1.7 A_{oh}^2}\right)^2} \le \phi \left(\frac{V_c}{b_w d} + \frac{2}{3}\sqrt{f_{ck}}\right)$$

### 2.3. 사용성 한계상태 (처짐 및 균열, KDS 14 20 30)
* **유효단면2차모멘트 ($I_e$, Branson 식)**:
  $$I_e = \left(\frac{M_{cr}}{M_a}\right)^3 I_g + \left[1 - \left(\frac{M_{cr}}{M_a}\right)^3\right] I_{cr} \le I_g$$
* **장기처짐 증폭계수 ($\lambda_\Delta$)**:
  $$\lambda_\Delta = \frac{\xi}{1 + 50\rho'}, \quad \Delta_{total} = \Delta_{elastic} + \lambda_\Delta \Delta_{sustained} \le \frac{L}{240} \text{ or } \frac{L}{480}$$
* **직접 균열폭 검토 ($w_{max}$)**:
  $$w = 1.08 \beta \epsilon_s \sqrt[3]{d_c A} \le w_{lim} \quad (0.3\,\text{mm} \sim 0.4\,\text{mm})$$

## 4. Python & Web 신규 구현 아키텍처

```text
src/
├── engine/rc/
│   ├── __init__.py
│   ├── beam.py                # RC 보 설계 엔진 (휨/전단/비틀림/처짐)
│   └── rebar_layout.py        # 철근 단면 배근 및 간격/피복 자동 계산기
├── api/
│   ├── schemas/rc_beam.py     # Pydantic 입력/출력 DTO 모델
│   └── routes/rc_beam.py      # FastAPI 엔드포인트 (/api/v1/rc/beam/check, /design)
└── web/static/js/
    ├── renderer2d.js          # HTML5 Canvas 2D 배근 단면 렌더러
    └── beam_view.js           # 보 인터랙티브 뷰어
```

### 4.1. 클래스 및 Pydantic 스키마 설계
* **[`src/engine/rc/beam.py`](file:///f:/PyProject/AltDP_3rd/src/engine/rc/beam.py)**:
  - `class RCBeamSection`: 단면 치수($b, h$), 피복두께, $f_{ck}, f_y, f_{yt}$.
  - `class RCBeamDesignResult`: $\phi M_n$, $\phi V_n$, $\phi T_n$, $I_e$, $\Delta_{long}$, $w_{crack}$, DCR 요약.
  - `check_beam_section(section: RCBeamSection, forces: SectionForces) -> RCBeamDesignResult`
  - `auto_design_rebar(section: RCBeamSection, forces: SectionForces) -> RebarLayout`
* **[`src/web/static/js/renderer2d.js`](file:///f:/PyProject/AltDP_3rd/src/web/static/js/renderer2d.js)**:
  - `drawRCBeamSection(canvas, sectionData)`: 콘크리트 외곽선, 주철근 원형 심볼, 스터럽 폐합 루프, 치수선 및 레이블 렌더링.

# 요구사항 11-1: 통합 반응형 웹 대시보드 및 디자인 시스템

## 1. 개요 및 목적 (Overview & Goals)

### 1.1. 배경 및 목적
* AltDP_3rd의 전 부재(RC 보·기둥·전단벽·슬래브·기초·옹벽, 철골 보·기둥·가새·접합부·엔드플레이트·베이스플레이트, SRC/CFT 합성부재, 알루미늄, 보수보강)를 일원화된 단일 인터페이스에서 직관적으로 제어할 수 있는 **통합 반응형 웹 대시보드 UI/UX**를 구축합니다.
* CSS 변수(Design Tokens) 기반의 세련된 다크/라이트 테마 시스템, Glassmorphism 스타일, DCR 상태 인디케이터(Safe/Warning/Danger), 직관적인 파라메트릭 입력 폼을 제공합니다.
* SRC 합성부재, 알루미늄, 보수보강을 위한 특수 부재 REST API 엔드포인트를 통합 라우팅하고 웹 프론트엔드와 완벽하게 바인딩합니다.

## 2. 세부 설계 및 인터페이스 규격

### 2.1. 디자인 토큰 시스템 (`design_tokens.css`)
* **Color Palette (CSS Variables)**:
  - Dark Theme: `--bg-primary: #0f172a`, `--bg-secondary: #1e293b`, `--bg-card: rgba(30, 41, 59, 0.7)`, `--text-primary: #f8fafc`, `--text-secondary: #94a3b8`, `--accent: #38bdf8`, `--accent-glow: rgba(56, 189, 248, 0.2)`
  - Light Theme: `--bg-primary: #f8fafc`, `--bg-secondary: #ffffff`, `--bg-card: rgba(255, 255, 255, 0.8)`, `--text-primary: #0f172a`, `--text-secondary: #64748b`, `--accent: #0284c7`
  - DCR Status: `--status-safe: #22c55e`, `--status-warning: #f59e0b`, `--status-danger: #ef4444`
* **Typography & Layout**:
  - Font: `Pretendard`, `Inter`, system-ui
  - Spacing & Radius: 4px 그리드 시스템, `--radius-sm: 6px`, `--radius-md: 10px`, `--radius-lg: 16px`
  - Glassmorphism: `backdrop-filter: blur(12px)`, `border: 1px solid rgba(255, 255, 255, 0.1)`

### 2.2. 통합 대시보드 탭 및 컴포넌트 아키텍처 (`index.html`)
* **상단 헤더 (Header)**:
  - 프로젝트 로고, 부재 선택 메가 드롭다운/탭 (RC / Steel / Special / Report / Section DB).
  - 테마 토글 버튼 (Dark / Light 모드), 단위계 선택(kN·m / mm, MPa).
* **좌측 파라메트릭 입력 사이드바 (Input Panel)**:
  - 재료 물성치($f_{ck}, f_y, f_{ys}, F_y, E_s$).
  - 단면 형상 치수 및 형강 DB 선택 (KS D 3502 H형강 자동 로드).
  - 철근 배근 / 볼트 접합 / 보강재 파라미터.
  - 설계 계수하중 조합($P_u, M_{ux}, M_{uy}, V_{ux}, V_{uy}, T_u$).
* **중앙 인터랙티브 캔버스 & 뷰어 영역 (Viewer Panel)**:
  - 상단 탭: 2D 배근 단면도 / 3D P-M 상관도 곡선 / 실시간 DCR 게이지.
  - 실시간 안전율 판정 뱃지 및 DCR 프로그레스 바.
* **우측/하단 실시간 계산 요약 & 계산서 프리뷰 (Summary & Report Panel)**:
  - 설계 검토 항목별 DCR 리스트 테이블 (휨, 전단, 비틀림, 좌굴, 처짐, 균열, 볼트 지압 등).
  - 원클릭 A4 구조계산서 모달 뷰어 및 Excel 익스포트 버튼.

### 2.3. 특수 부재 REST API 엔드포인트 구축 (`src/api/routes/special.py`)
* `POST /api/v1/special/cft-column/check`: CFT 각형/원형 기둥 좌굴 및 압축 내력 검토.
* `POST /api/v1/special/src-column/check`: SRC 매입형 기둥 설계강도 검토.
* `POST /api/v1/special/composite-beam/check`: 합성보 유효폭, 스터드 전단강도, 휨강도 검토.
* `POST /api/v1/special/aluminum/check`: 알루미늄 부재 휨/압축/인장/국부좌굴 검토.
* `POST /api/v1/special/retrofit/check`: CFRP 및 강판 보강 휨/전단 내력 증진 검토.

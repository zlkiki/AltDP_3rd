## 2. 상세 구현 명세

### 2.1. 기술 문서 개정 (`docs/07_web_application_ui_ux_specification.md`)
* docs 13의 4대 메인 폼뷰 구조와 3대 모드 워크플로우를 docs 07에 모던 웹(HTML5/CSS3/Vanilla JS) 규격으로 완전 통합 반영.

### 2.2. 디자인 시스템 및 CSS 아키텍처 (`src/web/static/css/`)
* **`design_tokens.css`**: Dark Slate(`--bg-canvas: #0f172a`, `--card-bg: #1e293b`) 및 Clean Light 테마 변수, DCR 컬러 스펙트럼(안전: Green, 경고: Amber, NG: Red).
* **`ribbon.css`**: Midas Design+ 스타일 모던 리본 바 탭(메인, RC, 강구조, 합성/특수, FEM, 설정) 및 리본 버튼 그룹, 툴바 스타일링.
* **`views.css`**: 4대 폼뷰 컨테이너, 반응형 스플릿 뷰(Split Pane), 드래그 리사이저, 모달 다이얼로그 스타일.

### 2.3. 전역 웹 레이아웃 셸 및 라우터 (`src/web/templates/base.html`, `src/web/static/js/app.js`)
* **`base.html`**:
  - 상단 헤더: 프로젝트 명, 단위계 전환기(SI/MKS/US), 설계기준 선택(KDS 14 20 00 / KDS 14 31 00), 다크/라이트 테마 토글.
  - 리본 네비게이션: 부재별 모듈 빠른 실행 탭.
  - 메인 네비게이션 탭: 4대 폼뷰 스위처 (`Memb View`, `List View`, `Draw View`, `Qntt View`).
* **`app.js` (SSOT State Store)**:
  - 전역 상태 관리: 현재 활성 부재, 현재 폼뷰, 단위계, DCR 캐시.
  - 0.05초 이내 뷰 전환 및 화면 상태 유지 라우팅.

## 2. 상세 구현 명세

### 2.1. 단철근 및 복철근 휨 강도 해석 (KDS 14 20 20)
* **유효깊이 및 중립축 계산**:
  - 인장철근 유효깊이 $d = h - d_c$, 압축철근 유효깊이 $d'$
  - 등가 직사각형 응력블록 계수: $\alpha_1, \beta_1$ (콘크리트 강도 $f_{ck}$별 기준식 적용)
  - 압축철근 항복 판정:
    - $\epsilon_s' = \epsilon_{cu} \frac{c - d'}{c}$
    - $\epsilon_s' \ge \epsilon_y \implies f_s' = f_y$
    - $\epsilon_s' < \epsilon_y \implies f_s' = E_s \epsilon_s' = E_s \epsilon_{cu} \frac{c - d'}{c}$ (2차 방정식 풀이: $\alpha_1 f_{ck} \beta_1 b c^2 + (A_s' E_s \epsilon_{cu} - A_s f_y) c - A_s' E_s \epsilon_{cu} d' = 0$)
* **설계 휨강도 $\phi M_n$**:
  - 공칭 휨강도: $M_n = (A_s f_y - A_s' f_s') (d - a/2) + A_s' f_s' (d - d')$
  - 최외단 인장변형률 $\epsilon_t = \epsilon_{cu} \frac{d_t - c}{c}$ 에 따른 강도감소계수 $\phi$ 적용
* **최소/최대 철근비 검토**:
  - 최소 철근량: $A_{s,min} = \max\left(\frac{0.25\sqrt{f_{ck}}}{f_y} b_w d, \frac{1.4}{f_y} b_w d\right)$
  - 연성 확보 한계: $\epsilon_t \ge 0.004$ (인장지배 단면 여부 판정)

### 2.2. 전단 및 비틀림 강도 및 상호작용 해석 (KDS 14 20 22)
* **콘크리트 및 전단철근 전단강도**:
  - $V_c = \frac{1}{6} \lambda \sqrt{f_{ck}} b_w d$
  - $V_s = \frac{A_v f_{yt} d}{s} \le \frac{2}{3}\sqrt{f_{ck}} b_w d$
  - $\phi V_n = \phi_v (V_c + V_s)$ ($\phi_v = 0.75$)
  - 최소 전단철근량 $A_{v,min} = 0.0625 \sqrt{f_{ck}} \frac{b_w s}{f_{yt}} \ge \frac{0.35 b_w s}{f_{yt}}$
  - 최대 스터럽 간격 $s_{max} = \min(d/2, 600\text{mm})$ ($V_s > \frac{1}{3}\sqrt{f_{ck}} b_w d$일 때 $\min(d/4, 300\text{mm})$)
* **비틀림 설계 ($T_u, T_{cr}, T_n$)**:
  - 균열 비틀림모멘트: $T_{cr} = \frac{1}{3} \lambda \sqrt{f_{ck}} \left(\frac{A_{cp}^2}{p_{cp}}\right)$
  - 비틀림 검토 한계: $T_u \le \phi \frac{T_{cr}}{4}$ 인 경우 비틀림 무시
  - 비틀림 횡방향 철근: $\frac{A_t}{s} = \frac{T_n}{2 A_o f_{yt} \cot\theta}$ ($A_o = 0.85 A_{oh}, \theta = 45^\circ$)
  - 비틀림 종방향 철근: $A_l = \left(\frac{A_t}{s}\right) p_h \left(\frac{f_{yt}}{f_y}\right) \cot^2\theta$
  - 전단-비틀림 단면 크기 상한 검토:
    $$\sqrt{\left(\frac{V_u}{b_w d}\right)^2 + \left(\frac{T_u p_h}{1.7 A_{oh}^2}\right)^2} \le \phi \left(\frac{V_c}{b_w d} + \frac{2}{3}\sqrt{f_{ck}}\right)$$

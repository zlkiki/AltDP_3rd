# 요구사항 22-3: Phase V1-1 Step 3 RC 보 2D VDraw 캔버스 3단 배근도 인터랙션 명세서

## 1. 개요 및 원본 그래픽스 리소스 매핑

본 문서는 **RC 보 (`rc_beam`)**의 **Step 3 (2D VDraw 캔버스 동적 가변 3단 단부/중앙부 횡단면 배근도 인터랙션)** 구현을 위한 상세 요구사항 명세서입니다.
원본앱의 VDraw 그래픽스 엔진 드로잉 알고리즘을 HTML5 Canvas 2D에 완벽 구현하여, 엔지니어가 단면과 배근 상태를 직관적으로 확인하고 시각적으로 검토할 수 있도록 합니다.

* **부재 및 모듈 식별자**: `rc_beam` (카탈로그 No. 1, Tier 1 플래그십)
* **담당 소스 파일**:
  - `src/web/static/js/visual/vector_rc_beam.js` (신규 RC 보 2D 렌더러 모듈)
  - `src/web/static/js/modules/rc_beam/rc_beam_module.js` (3단 뷰포트 디스패치 연동)
  - `src/web/static/js/components/graphic_viewport.js` (동적 1~3단 뷰포트 관리자)
* **권장 AI 모델**: ⚙️ **Medium** - Canvas 2D 그래픽스 컨텍스트 연산, 기하 변환, 마우스 인터랙션 이벤트 최적화
* **1순위/2순위 그래픽스 SSOT**:
  - `decompiled_src/DPLUS_VDraw.dll_symbols.txt` (`CODABeamBase`, `CODADrawTool`, `CVDrawView`)
  - 원본 원본앱 보 그래픽스 뷰 (세로 긴 정보부에 맞춤: 단부( i ), 중앙( m ), 단부( j ) 3개 횡단면 상세도)

## 2. 2D 캔버스 동적 가변 3단 뷰포트(Vertical 3-Station Viewport) 분할 구조

RC 보 캔버스는 세로로 긴 웹 그래픽 정보부(Pane 3)에 최적화하여 **원본앱 명칭을 1:1 반영한 세로 3단 독립 뷰포트**로 분할 렌더링됩니다:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [1단 뷰포트: 단부( i ) 단면 배근도 (End-I Section)]                      [Fit] [Zoom]  │
│  - 콘크리트 외곽선 (직사각형 또는 T형 플랜지) 및 해치 패턴                              │
│  - 135° 내진 갈고리(Seismic Hook) 폐합 스터럽 렌더링                                    │
│  - 단부 상부 부모멘트 다단 주철근 솔리드 심볼 및 측면 표피/비틀림 철근                 │
│  - 외곽 치수선 (bw, h, d, d') 및 철근 규격 지시선 태그                                  │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ [2단 뷰포트: 중앙( m ) 단면 배근도 (Center-M Section)]                   [Fit] [Zoom]  │
│  - 콘크리트 외곽선 및 정모멘트 인장 하부 다단 주철근 솔리드 심볼                         │
│  - 135° 내진 갈고리 폐합 스터럽 (중앙부 간격 적용)                                      │
│  - 외곽 치수선 및 배근 태그 지시선                                                     │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ [3단 뷰포트: 단부( j ) 단면 배근도 (End-J Section)]                      [Fit] [Zoom]  │
│  - 우단부 콘크리트 외곽선 및 상하부 다단 주철근                                         │
│  - 외곽 치수선 및 배근 태그 지시선                                                     │
└────────────────────────────────────────────────────────────────────────────────────────┘
```
*(참고: 잔존 임시 그래픽 모듈이었던 종단면 배근선은 제거하고, 원본앱 1:1 단면 상세도를 큼직하게 렌더링)*

## 3. 세부 그래픽스 렌더링 알고리즘 명세

### 3.1. 개별 단면 독립 렌더링 엔진 (`renderStationSection`)
1. **스케일링 및 중앙 정렬**:
   - 각 단(단부 I, 중앙 M, 단부 J) 캔버스의 독립 종횡비에 맞춰 $b, h, b_f$의 최대 치수 기반 자동 스케일링.
2. **콘크리트 단면 외곽선**:
   - 직사각형 보: `ctx.strokeRect(-bw/2, -h/2, bw, h)`, 내부 슬레이트 채우기.
   - T형 보: 유효플랜지폭 $b_f$와 두께 $h_f$가 반영된 T자형 다각형 패스 생성.
3. **폐합 스터럽 (Stirrup) 렌더링**:
   - 외곽 피복두께 $c_v$ 옵셋된 둥근 모서리 사각 루프.
   - 상단 모서리에 135° 내진 갈고리(Seismic Hook) 굴곡선 완벽 재현 ($r_{bend} = 2 d_{tie}$).
4. **상/하부 다단 주철근 심볼 렌더링**:
   - 1단 철근: 스터럽 내측 안착 좌표 산출 ($x_i, y_i$).
   - 2단 철근: 1단 철근으로부터 수직 순간격 25mm 띄운 2단 위치에 정렬.
   - 철근 직경($d_b$)에 비례하는 원형 솔리드 채우기 및 외곽선 스트로크.
5. **치수선 및 배근 지시선 태그 (Dimensions & Tags)**:
   - 보 단면 폭 $b_w$, 전체 높이 $h$, 유효높이 $d$ 외곽 치수선 및 치수 보조선.
   - 상부/하부 주철근에 인출선(Leader line)을 뽑아 `4-D25 (2단: 2-D25)` 형식의 텍스트 태그 부착.
   - 스터럽에 인출선 부착하여 `D10 @150` 표기.

---

## 4. 인터랙션 및 이벤트 처리 명세

1. **줌 및 팬 (Zoom & Pan)**:
   - 마우스 휠 줌(0.5x ~ 3.0x), 마우스 드래그 팬(Pan), 상단 툴바 `[Fit]` 클릭 시 자동 중앙 정렬 복귀.
2. **마우스 호버 툴팁**:
   - 철근 심볼 호버 시 툴팁 표출 (예: `상부 1단 주철근 4-D25 (As = 2,027 mm²)`).
3. **실시간 파라메터 반응**:
   - Pane 2의 치수($b, h$) 또는 철근 배근 변경 시 `EventBus`를 통해 100ms 내 3대 단면 동시 재렌더링.

## 5. 완료 검증 기준 (Acceptance Criteria)

- [x] **[세로 3단 뷰포트]**: Pane 3 그래픽 정보부에 단부( i ), 중앙( m ), 단부( j ) 3단 분할 카드가 원본앱 명칭으로 배치됨.
- [x] **[잔존 모듈 제거]**: 상단에 임시로 표시되던 종단면 배근선 및 BMD/SFD 오버레이가 완전히 제거됨.
- [x] **[단면 드로잉 무결성]**: 각 단면별로 치수선, 피복두께, 135° 내진갈고리 스터럽, 다단배근(1단/2단), 태그가 큼직하고 시원하게 렌더링됨.
- [x] **[인터랙션]**: 각 뷰포트별 줌/팬 및 Fit 버튼이 독립적으로 원활히 동작함.

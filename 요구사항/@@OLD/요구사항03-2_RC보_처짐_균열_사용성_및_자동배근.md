## 2. 상세 구현 명세

### 2.1. 사용성 한계상태 (처짐 및 균열) 계산
* **Branson 유효단면2차모멘트 ($I_e$)**:
  - 균열모멘트: $M_{cr} = \frac{f_r I_g}{y_t}$ ($f_r = 0.63 \lambda \sqrt{f_{ck}}$)
  - 균열단면2차모멘트: $I_{cr}$ (인장측 균열을 고려한 변환단면 해석)
  - $I_e = \left(\frac{M_{cr}}{M_a}\right)^3 I_g + \left[1 - \left(\frac{M_{cr}}{M_a}\right)^3\right] I_{cr} \le I_g$ ($M_a \le M_{cr}$일 때 $I_e = I_g$)
* **처짐 평가**:
  - 탄성 즉시처짐: $\Delta_i$ (하중 조건별 탄성 처짐식 적용)
  - 장기처짐 증폭계수: $\lambda_\Delta = \frac{\xi}{1 + 50\rho'}$ (하중 지속기간 계수 $\xi$: 5년 이상 2.0, 12개월 1.4 등)
  - 총 처짐: $\Delta_{total} = \Delta_{immediate} + \lambda_\Delta \Delta_{sustained}$
  - 한계 처짐 허용치($L/240, L/480$) 대비 검토
* **직접 균열폭 ($w$) 산정**:
  - Frosch 식 또는 Gergely-Lutz 식 기반 균열폭:
    $$w = 1.08 \beta \epsilon_s \sqrt[3]{d_c A} \le w_{lim} \quad (0.3\,\text{mm} \sim 0.4\,\text{mm})$$
  - 인장철근 응력 $f_s = \frac{M_s}{A_s (d - kd/3)}$ 산정

### 2.2. 철근 단면 자동 배근 엔진 (`src/engine/rc/rebar_layout.py`)
* **KDS 배근 규준 검토**:
  - 철근 순간격: $\max(25\text{mm}, d_b, 1.33 \times \text{골재최대치수})$
  - 최소 피복두께: 실내 40mm, 실외 50mm 규준
* **자동 배근 탐색 알고리즘**:
  - 표준 철근 규격(D10, D13, D16, D19, D22, D25, D29, D32) DB 연계
  - 소요 철근량($A_{s,req}$)을 만족하는 최소 철근량 조합 도출
  - 폭($b$) 내 1단 배근 가능 여부 판정, 초과 시 2단 배근 자동 분할
  - 횡방향 스터럽 지름 및 간격 최적화 자동 선택

## 2. 세부 개발 사양 (Detailed Specifications)

### 2.1. 3중 필터 네비게이션 & 즐겨찾기 상시 고정 시스템
* **대상 파일**: `src/web/static/js/components/sidebar_nav.js`, `src/web/static/css/tree_menu.css`
* **카테고리 Pills 탭 필터 (상단 가로 스크롤/탭)**:
  1. `[전체 (ALL)]`: 61종 전체 모듈 전개.
  2. `[⭐ 즐겨찾기]`: 사용자가 별표를 누른 모듈 및 부재만 최상단 집중 렌더링.
  3. `[RC 콘크리트]`: 보, 기둥, 전단벽, 슬래브, 기초, 옹벽, 지하외벽, 앵커, 코벨.
  4. `[STEEL 강구조]`: 철골보, 철골기둥, 가새, 트러스, 크레인거더, 접합부 5종, 베이스플레이트.
  5. `[SRC / PC]`: SRC 기둥/보, CFT 기둥, 프리캐스트 보/슬래브, 더블티, 할로우코어.
  6. `[ALU 알루미늄]`: 알루미늄 보/기둥, 커튼월 멀리온, 루버 프레임.
  7. `[RFM 보강]`: CFRP 탄소섬유판/시트, 강판접착 보강, 단면증설.
  8. `[기초 / 특수]`: 독립/복합/줄기초, 말뚝기초, FEM 매트기초.
* **즐겨찾기(Favorites ⭐) 인터랙션**:
  - 모듈 및 부재명 우측에 `☆`/`★` 토글 아이콘 배치.
  - 클릭 시 `localStorage.getItem('AltDP_favorites')`에 JSON 배열로 영속화.
  - 탭과 무관하게 사이드바 최상단에 `[⭐ 즐겨찾기]` 섹션이 상시 고정되어 실무 빈출 부재(RC보, H형강기둥 등)로 1클릭 즉시 진입.

### 2.2. 3단계 계층 WorkTree 및 DCR 2단계 텍스트 표기
* **트리 계층 구조**:
  - **Level 1 (대분류)**: 예: `콘크리트 구조 (RC)`
  - **Level 2 (단위 모듈)**: 예: `RC 보 (Beam)` + 등록 부재 수 배지 `[2]`
  - **Level 3 (개별 등록 부재)**: 예: `1F-B1`, `1F-B2`
* **DCR 2단계 텍스트 표기 (불필요한 칩/배경색 제거, 폰트 컬러로 시인성 극대화)**:
  - **OK (`DCR ≤ 1.000`)**: **녹색 굵은 텍스트 (`OK 0.807`)**.
  - **NG (`DCR > 1.000`)**: **빨간색 굵은 텍스트 (`NG 1.052`)**.
  - **불합격 부재 클릭 시 동작**: 해당 부재 활성화와 동시에 우측 4열 계산서의 불합격(`N.G`) 판정 수식 위치로 자동 스크롤 연동.

### 2.3. 스마트 자동 숨김 (Auto-Hide) & 고정핀 (📌) 인터랙션
* **고정핀 ON (`pinned: true`)**: 워크스페이스 좌측에 상시 고정 영역으로 배치.
* **고정핀 OFF (`pinned: false`)**:
  - 마우스가 사이드바를 벗어나면 3초 후 슬라이드 애니메이션으로 자동 축소(아이콘 바 형태).
  - 마우스 오버 시 즉시 확장 전개.
* **단축키 지원**: `Ctrl + B`로 사이드바 접기/펼치기 즉시 토글.

## 3. 세부 작업 5단계 공정 (Step 1 ~ Step 5)
* **Step 1: 사이드바 컴포넌트 뼈대 및 CSS 구조화**
  - `src/web/static/css/tree_menu.css` Pills 탭, 즐겨찾기 스타, 트리 노드, DCR 텍스트 컬러 스타일 정의.
* **Step 2: 61종 카탈로그 메타 기반 트리 렌더러 구현**
  - `docs/04` 카탈로그와 `catalog.js`를 연동하여 카테고리별 3단계 계층 렌더링.
* **Step 3: 즐겨찾기(⭐) 및 LocalStorage 영속화 구현**
  - 별표 클릭 이벤트, 영속화 처리, 최상단 섹션 동적 주입.
* **Step 4: DCR 상태 바인딩 & 자동 숨김/고정핀 인터랙션**
  - 계산 결과 수신 시 DCR 텍스트 갱신 및 NG 클릭 시 계산서 앵커 스크롤.
  - 마우스 타이머(3초) 기반 자동 수축 및 `Ctrl+B` 단축키 바인딩.
* **Step 5: DOM 렌더링 검증 및 Git 커밋**
  - 브라우저 필터링, 즐겨찾기 추가/삭제, DCR 텍스트 표기 수동/자동 검증 후 커밋/푸시.

## 4. 수용 기준 및 1:1 체크리스트 (Acceptance Criteria)
- [ ] 사이드바 상단에 8개 카테고리 Pills 탭이 존재하며, 클릭 시 해당 카테고리 모듈만 정확히 필터링되는가?
- [ ] 모듈 우측의 별표(⭐) 클릭 시 즐겨찾기에 등록되고, 브라우저 새로고침 후에도 유지되는가?
- [ ] 트리가 대분류 → 단위 모듈 → 개별 등록 부재 3단계로 정확히 전개되는가?
- [ ] DCR 상태가 배경 칩 없이 깔끔한 녹색(OK)/빨간색(NG) 글자로 표기되는가?
- [ ] `Ctrl + B` 입력 시 사이드바가 즉각 토글되며, 고정핀(📌) 해제 시 3초 후 자동 축소되는가?

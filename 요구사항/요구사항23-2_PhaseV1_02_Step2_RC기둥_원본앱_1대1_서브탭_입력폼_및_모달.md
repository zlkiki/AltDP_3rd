## 2. 원본앱 1:1 4대 서브탭 UI 구조

`form_rc_column.js`는 원본 원본앱의 다이얼로그 계층을 1:1로 웹 탭 인터페이스로 완벽히 재현하며, 하단에 3버튼 통합 액션 툴바(`[💾 적용] [⚡ 검토] [✨ 설계]`)를 제공합니다:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [Left-Sub Pane 2: RC 기둥 설계/검토 입력창 IDD_RCS_COLUMN_PMODE_DLG]                   │
├───────────────┬───────────────┬───────────────────────┬────────────────────────────────┤
│ Tab 1: 단면/재료 │ Tab 2: 철근배근 │ Tab 3: 부재력/하중조합 │ Tab 4: 세장비/골조조건           │
├───────────────┴───────────────┴───────────────────────┴────────────────────────────────┤
│ [💾 적용 (Apply)]           [⚡ 검토 (Check)]                  [✨ 설계 (Design)]       │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 2.1. Tab 1: 단면 및 재료 (Section & Material)
* **단면 형상 라디오 버튼**:
  - `IDC_RADIO_SHAPE_RECT`: 직사각형 기둥 ($B \times H$)
  - `IDC_RADIO_SHAPE_CIRC`: 원형 기둥 ($D$)
* **단면 치수 입력 필드**:
  - `width` ($B$): 폭 (기본값: 500 mm)
  - `height` ($H$): 높이 (기본값: 500 mm)
  - `diameter` ($D$): 원형 지름 (원형 선택 시 활성화, 기본값: 600 mm)
  - `length` ($L_u$): 기둥 비지지 층고 길이 (기본값: 3,500 mm)
  - `cover`: 유효 순피복 두께 (기본값: 40 mm)
* **재료 물성치 드롭다운 (KDS 표준 규격)**:
  - 콘크리트 강도 ($f_{ck}$): C21, C24, C27, C30, C35, C40, C50, C60 (기본: C27)
  - 주철근 강도 ($f_y$): SD400, SD500, SD600 (기본: SD400)
  - 띠철근 강도 ($f_{ys}$): SD400, SD500 (기본: SD400)
* **횡철근 형식 라디오 버튼**:
  - 띠철근 (Tied, $\phi = 0.65$)
  - 나선철근 (Spiral, $\phi = 0.70$)

### 2.2. Tab 2: 주철근 및 띠철근 배근 (Reinforcement)
* **주철근 배열 방식 콤보박스**:
  - `SYMMETRIC_4SIDE`: 4면 대칭 균등배열 (가장 일반적인 빌딩 기둥)
  - `2SIDE_X`: X축 대칭 배근
  - `2SIDE_Y`: Y축 대칭 배근
  - `CIRCULAR`: 원주 방향 균등 원형 배열 (원형 기둥 선택 시 자동 전환)
* **코너 및 중간 주철근 파라미터**:
  - 코너 철근: 호칭경 선택 (D19, D22, D25, D29, D32, D35), 기본 4-D25
  - X변 중간 철근: 호칭경 드롭다운, 편측 개수 ($0 \sim 10$개)
  - Y변 중간 철근: 호칭경 드롭다운, 편측 개수 ($0 \sim 10$개)
* **횡철근 (띠철근/후프) 파라미터**:
  - 호칭경 드롭다운: D10, D13, D16 (기본: D10)
  - 배근 간격 ($s$): 수치 입력 (기본: 300 mm)
  - X방향 다리수 ($Legs_X$): 2각, 3각, 4각 선택
  - Y방향 다리수 ($Legs_Y$): 2각, 3각, 4각 선택
* **배근 상세 설정 버튼 (`...`)**: 클릭 시 `IDD_RCS_COLM_REBAR_DLG` 모달 호출

### 2.3. Tab 3: 설계 부재력 및 하중조합 (Design Loads)
* **단일 검토 부재력 입력부**:
  - 축하중 ($P_u$): 압축력 (kN, 기본: 1,500 kN)
  - 상단 휨모멘트 ($M_{ux,top}, M_{uy,top}$): kN·m (기본: 120, 80 kN·m)
  - 하단 휨모멘트 ($M_{ux,bot}, M_{uy,bot}$): kN·m (기본: -80, -50 kN·m)
  - 전단력 ($V_{ux}, V_{uy}$): kN (기본: 90, 60 kN)
* **다중 하중조합 (LCB) 테이블 그리드**:
  - 행 추가/삭제/일괄 임포트 기능
  - 하중조합 이름, $P_u, M_{ux}, M_{uy}, V_{ux}, V_{uy}$ 컬럼 그리드
  - "최악 하중(Envelope Governing LCB) 자동 선택" 토글 스위치

### 2.4. Tab 4: 세장비 및 골조 구속조건 (Slenderness & Frame)
* **골조 횡구속 여부 라디오**:
  - 횡구속 골조 (Braced / Non-sway): 세장비 한계 $34 - 12(M_1/M_2)$ 적용
  - 횡비구속 골조 (Unbraced / Sway): 세장비 한계 22 적용
* **유효좌굴길이계수**:
  - $k_x$: 기본 1.0 (양단 회전 자유 시뮬레이션)
  - $k_y$: 기본 1.0
* **지속하중 비 ($\beta_{dns}$)**:
  - 수치 슬라이더 및 입력 필드 ($0.0 \sim 1.0$, 기본: 0.20)
* **장주 해석 옵션 체크박스**:
  - `[x] KDS 14 20 20 모멘트 확대계수법 자동 적용`
  - `[x] 최소 편심 모멘트 (15 + 0.03h) 자동 고려`

## 3. 기둥 전용 서브 대화상자 모달 2종

### 3.1. 기둥 철근 배근 상세 모달 (`IDD_RCS_COLM_REBAR_DLG`)
* **크로스타이(Cross-tie) / 내부 보강대근 옵션**:
  - 90°-135° 교대 배치 갈고리 또는 양단 135° 내진 갈고리 선택
  - 다이아몬드형 내부 띠철근 자동 배치 토글
* **피복 및 철근 순간격 검증**:
  - 골재 최대치수 및 KDS 최소 순간격($\ge 25\text{ mm}$, $\ge 1.5 d_b$) 자동 계산 및 경고 라벨

### 3.2. P-M 뷰어 인터랙티브 확장 모달
* 3D P-M 곡면을 확대하여 마우스로 3차원 회전 관찰 및 임베디드 2D 슬라이스 투영 보기 기능 제공.

## 4. 유효성 검사 및 실시간 상태 동기화 규약

1. **실시간 유효성 검증**:
   - $B, H < 100\text{ mm}$ 이거나 주철근비 $\rho_g < 1.0\%$ 또는 $> 8.0\%$ 일 경우 인풋 테두리 경고 색상(`#ef4444`) 표시 및 인라인 툴팁 안내.
2. **ProjectStore 연동**:
   - 사용자가 폼 필드를 변경하는 즉시 `ProjectStore.updateActiveMember(formData)`를 디바운스(50ms) 호출하여 Step 3(캔버스) 및 Step 4(계산서)로 즉각 상태를 전파.

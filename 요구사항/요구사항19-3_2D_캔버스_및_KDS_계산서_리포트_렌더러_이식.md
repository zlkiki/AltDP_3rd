# [요구사항19-3] 2D 캔버스 및 KDS 계산서 리포트 렌더러 이식

## 1. 개요 및 목적
* 그래픽 정보부(Pane 3)와 KDS 계산서 뷰포트(Pane 4)를 담당하는 2D Canvas / Vector SVG 서브 렌더러군과 re-DCR 기반 A4 KDS 계산서 엔진을 완전 이식합니다.
* **소스 직접 재활용 & 토큰 효율성 원칙**: `AltDP_2nd/web/js/visual/` 및 `AltDP_2nd/web/js/report/`의 검증된 시각화 렌더러와 A4 계산서 생성기를 처음부터 재작성하지 않고 그대로 직접 복사/이식하여 토큰 소모를 원천 차단하고 시각화/수식 표현의 100% 무결성을 확보합니다.
* 폼 입력 시 2D 단면이 즉각 갱신되며, [검토] 클릭 시 A4 순백색 시트에 수식과 검토표가 정밀하게 렌더링되도록 구현합니다.

---

## 2. 세부 개발 작업 명세

### 2.1. 2D Canvas & Vector SVG 시각화 모듈군 이식 (`src/web/static/js/visual/`)
1. **코어 및 레전드 바**:
   - `canvas_core.js`: 반응형 종횡비 유지, 테마 팔레트 연동, 단위계 자동 포맷팅.
   - `legend_bar.js`: DCR 수치 뱃지 및 4단계 컬러(안전/적합/경고/초과) 게이지 바.
   - `canvas_renderer.js`: 지오메트리 타입(`rc_rect`, `rc_column`, `steel_h`, `footing`, `slab` 등)별 디스패처.
2. **모듈형 2D Canvas 렌더러**:
   - `draw_rc.js`: RC 26종 (보 1/2단 배근, 스터럽, 기둥 주근/대근, T형보, 기초 말뚝).
   - `draw_steel.js`: Steel 13종 (H형강 플랜지/웨브, 강관, 베이스플레이트 앵커).
   - `draw_pc_misc.js`: PC/Misc 15종 (더블티, 브라켓, SRC 단면).
3. **고품질 SVG 벡터 렌더러 (`vector/`)**:
   - `vector_core.js`, `vector_rc_sec.js`, `vector_footing.js`, `vector_slab.js`, `vector_steel.js`, `vector_wall.js`.

### 2.2. A4 KDS 계산서 렌더러군 이식 (`src/web/static/js/report/`)
1. **보고서 코어 엔진**:
   - `result_renderer.js`: 계산 결과 수신 시 33종 특별 보고서 vs 21종 일반 보고서 자동 분기 렌더링.
   - `redcr_common_renderer.js`: 범용 4대 영역 KDS 리포트 조립기 (요약박스, Step-by-Step 수식, DCR 표).
2. **33종 특별 부재 전용 생성기 (`redcr/`)**:
   - `BeamReportGenerator.js`, `ColumnCheckReportGenerator.js`, `WallCheckReportGenerator.js`, `FootingReportGenerator.js`, `SlabReportGenerator.js`, `SteelReportGenerator.js`.
   - `detailWrapper.js`, `sheetFormulas.js`, `seismicSheetUtils.js`, `reportUnitTransform.js`.
   - `common/` (`formatHelpers.js`, `verdictBadge.js`, `memberHeader.js`, `overviewSection.js`, `levelFactorsSection.js`).
3. **상시 순백색 용지 & 줌 컨트롤러**:
   - `components/zoom_controller.js`: 50%~200% 슬라이더, `[-]`, `[100%]`, `[+]`, `[Fit]` 및 `Ctrl + Wheel` 줌 지원.
   - 다크 모드에서도 계산서 용지 내부(`.a4-sheet-container`)는 `#ffffff` 배경과 고대비 텍스트 유지.

## 3. 체크리스트 및 완료 검증
- [ ] 폼 입력값(폭, 높이, 철근) 변경 시 2D Canvas 단면도가 0.05초 내 반응하여 올바르게 그려지는가?
- [ ] 치수선(mm), 철근 기호 라벨, DCR 레전드 바가 캔버스에 깔끔하게 표출되는가?
- [ ] [검토] 버튼 클릭 시 계산서 뷰포트에 KDS 수식, 요약표, OK/NG 배지가 정상 렌더링되는가?
- [ ] 다크 테마 상태에서도 계산서 시트 영역은 완전한 순백색(`#ffffff`)을 유지하는가?
- [ ] `Ctrl + Wheel` 및 줌 슬라이더로 계산서 크기가 50%~200% 사이로 원활히 확대/축소되는가?
- [ ] 관련 렌더러 테스트 통과 확인.

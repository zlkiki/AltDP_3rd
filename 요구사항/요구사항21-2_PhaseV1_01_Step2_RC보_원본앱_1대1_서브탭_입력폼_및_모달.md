## 2. 원본앱 1:1 4대 서브탭 UI 구조

`form_rc_beam.js`는 원본 원본앱의 다이얼로그 계층을 1:1로 웹 서브탭 인터페이스로 완벽 재현합니다:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [RC 보 설계/검토 입력창: IDD_RCS_BEAM_PMODE_DLG]                                       │
├───────────────┬───────────────┬───────────────────────┬────────────────────────────────┤
│ Tab 1: 단면/재료 │ Tab 2: 철근배근 │ Tab 3: 부재력/하중조합 │ Tab 4: 사용성/처짐설정           │
└───────────────┴───────────────┴───────────────────────┴────────────────────────────────┘
```

### 2.1. Tab 1: 단면 및 재료 (Section & Material)
* **단면 형상 라디오 버튼**:
  - `IDC_RADIO_SHAPE_RECT`: 직사각형 보 ($b \times h$)
  - `IDC_RADIO_SHAPE_TEE`: T형 보 ($b_w, h, b_e, h_f$) - 선택 시 플랜지 입력란 동적 활성화
* **기하 치수 입력 필드**:
  - `width` ($b_w$): 복부 폭 (기본값: 400 mm)
  - `height` ($h$): 보 전체 춤 (기본값: 600 mm)
  - `length` ($L$): 유효 경간 (기본값: 6,000 mm)
  - `cover`: 인장측 순피복 두께 (기본값: 40 mm)
  - `cover_top`: 압축측 순피복 두께 (기본값: 40 mm)
  - `flange_width` ($b_e$): 플랜지 유효폭 (T형 선택 시 활성화, 기본값: 1,200 mm)
  - `flange_thickness` ($h_f$): 슬래브 두께 (T형 선택 시 활성화, 기본값: 150 mm)
* **재료 물성치 드롭다운 (KDS 표준 규격)**:
  - 콘크리트 강도 ($f_{ck}$): C21, C24, C27, C30, C35, C40, C50, C60 (기본: C27)
  - 주철근 강도 ($f_y$): SD400, SD500, SD600 (기본: SD400)
  - 전단철근 강도 ($f_{yt}$): SD400, SD500 (기본: SD400)
* **지지 조건 드롭다운**:
  - 단순지지 (Simple), 일단연속 (One-end Continuous), 양단연속 (Both Continuous), 캔틸레버 (Cantilever)

### 2.2. Tab 2: 철근 배근 (Reinforcement)
단부(End-I), 중앙부(Center-M), 단부(End-J)의 3구역 독립 배근 테이블을 제공합니다:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [위치별 주철근 및 스터럽 배근 테이블]                                                   │
├─────────┬──────────────────────────┬──────────────────────────┬────────────────────────┤
│ 위치     │ 상부 주철근 (Top Bars)   │ 하부 주철근 (Bot Bars)   │ 전단 스터럽 (Stirrup)  │
├─────────┼──────────────────────────┼──────────────────────────┼────────────────────────┤
│ End-I   │ 1단: 4-D25, 2단: 2-D25   │ 1단: 3-D22               │ D10 @150 (2 Legs)      │
│ Center-M│ 1단: 2-D22               │ 1단: 4-D25, 2단: 2-D25   │ D10 @250 (2 Legs)      │
│ End-J   │ 1단: 4-D25, 2단: 2-D25   │ 1단: 3-D22               │ D10 @150 (2 Legs)      │
└─────────┴──────────────────────────┴──────────────────────────┴────────────────────────┘
```
* **철근 호칭경 콤보박스**: D10, D13, D16, D19, D22, D25, D29, D32
* **다단 배근 지원**: 1단 및 2단 분리 입력 지원, 단간 순간격 25mm 자동 반영
* **비틀림 보강근 입력**:
  - 측면 종방향 비틀림 철근 호칭경 및 단면당 총 개수 (예: 4-D13)
* **배근 상세 설정 모달 버튼 (`...`)**: 클릭 시 `IDD_RCS_BEAM_REBAR_DLG` 모달 호출

### 2.3. Tab 3: 설계 부재력 및 하중조합 (Design Factored Loads)
* **단부 및 중앙부 계수하중 입력 테이블**:
  - $M_u^+$ (정모멘트, kN·m)
  - $M_u^-$ (부모멘트, kN·m)
  - $V_u$ (계수전단력, kN)
  - $T_u$ (계수비틀림모멘트, kN·m)
* **하중조합 일괄 입력 및 최악 LCB 선택 기능 지원**

### 2.4. Tab 4: 사용성 및 처짐 설정 (Serviceability & Deflection)
* **처짐 산정용 사용하중 입력**:
  - 사용 모멘트 ($M_{a,pos}, M_{a,neg}$): kN·m
  - 지속하중에 의한 모멘트 ($M_{sus}$): kN·m
* **처짐 한계비 선택**: $L/240$, $L/360$, $L/480$ (기본값: $L/240$)
* **노출 환경 등급 선택 (균열폭 허용치 $w_{lim}$ 결정)**:
  - 건조 환경 ($w_{lim} = 0.4\text{ mm}$)
  - 습윤 환경 ($w_{lim} = 0.3\text{ mm}$, 기본값)
  - 부식성 환경 ($w_{lim} = 0.2\text{ mm}$)

## 3. 상세 대화창(`...`) 서브 모달 명세

### 3.1. 배근 상세 설정 모달 (`IDD_RCS_BEAM_REBAR_DLG`)
* **갈고리 및 정착 형식**:
  - 주철근 단부 갈고리 (90° 표준갈고리 / 180° 반원형 갈고리)
  - 스터럽 갈고리 (135° 내진 갈고리 / 90° 표준 갈고리)
* **스터럽 다리수 상세 구성**:
  - 2각 (외곽 폐합 1개)
  - 4각 (외곽 폐합 1개 + 내부 U형 묶음 또는 크로스타이)
* **순간격 검토 옵션**: 철근 순간격 $s_{clear} \ge \max(25\text{ mm}, d_b, 1.33 \times d_{agg})$ 자동 경고

### 3.2. T형 플랜지 유효폭 자동 보조 모달
* **KDS 14 20 20 기준 유효플랜지폭 $b_e$ 자동 계산기**:
  - 경간 조건: $L / 4$
  - 인접 보 거리: $b_w + s_1/2 + s_2/2$
  - 슬래브 두께: $b_w + 16 h_f$
  - 위 3가지 조건 중 최솟값 자동 산출 및 폼 주입 버튼 제공

## 4. 프론트엔드 컴포넌트 아키텍처 및 이벤트 연동

1. **상태 관리 연동 (`ProjectStore`)**:
   - 폼 입력 변경 즉시 `ProjectStore.updateMemberData('rc_beam', data)` 발행.
   - 디바운스(Debounce 50ms)를 적용하여 과도한 재계산 방지 및 부드러운 입력감 유지.
2. **동적 탭 전환 및 유효성 검사 (Validation)**:
   - 각 탭 간 전환 시 `width > 0`, `height > 0`, `rebar_count > 0` 등 즉각적인 에러 하이라이팅.
   - 음수 입력 차단 및 자동 포커스 복구.

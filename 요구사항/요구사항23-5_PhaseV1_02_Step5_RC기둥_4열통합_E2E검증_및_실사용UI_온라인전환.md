## 2. 4-Pane 워크스페이스 실시간 3-View 동기화 파이프라인

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│ AltDP_3rd RC 기둥 4-Pane 워크스페이스 실시간 동기화 아키텍처 (ProjectStore 기반)                │
├─────────────────┬───────────────────────────────┬───────────────────────┬───────────────────────┤
│ [1열: 사이드바] │ [2열: Left-Sub (부재/폼)]     │ [3열: Center 그래픽]  │ [4열: Right 계산서]   │
│  RC > 기둥 선택 │  • Pane 1: 다중 부재 매니저   │  • 상단: 단면 배근도  │  - 5대 장구분 계산서  │
│  (Online 활성)  │  • Pane 2: 4대 서브탭 입력폼  │  • 하단: KDS P-M 곡선 │  - 8단계 KaTeX 전개   │
│                 │    - 단면/재료 (KS 콤보박스)  │  - 설계하중점 플롯/호버│  - 순백색 A4 프리뷰   │
│                 │    - 철근배근 (모달 연동)     │  - 휠 줌/팬/Fit       │  - O.K / N.G 상태     │
│                 │    - 부재력 / 세장비 입력     │  - 135° 절곡 띠철근   │  - 인쇄/PDF/Excel     │
└─────────────────┴───────────────────────────────┴───────────────────────┴───────────────────────┘
                                ▲                         ▲                        ▲
                                │ (Input Event)           │                        │
                                └────── [ProjectStore] ───┴────────────────────────┘
                                      (State Update <= 50ms)
```

### 2.1. 실시간 반응 속도 기준
- 2열 Left-Sub 입력폼에서 기둥 치수($B, H$), 주철근 호칭경, 띠철근 간격, 축력/모멘트 등을 수정하거나 슬라이더를 조작할 때:
  1. `ProjectStore` 상태 갱신: $\le 10\text{ ms}$
  2. 파이썬 백엔드 또는 웹 워커 파이버 P-M 재계산: $\le 40\text{ ms}$
  3. 3열 캔버스 단면도 및 P-M 곡선 리드로우: $\le 30\text{ ms}$
  4. 4열 A4 계산서 KaTeX 수식 재렌더링: $\le 50\text{ ms}$
  - **총 동기화 소요 시간 $\le 100\text{ ms}$**로 버벅임 없는 극상의 반응성 확보.

   - 클릭 시 더미 WIP 안내 카드가 아닌 실시간 4-Pane 워크스페이스가 즉각 마운트됨.

## 4. E2E 통합 테스트 시나리오 (`tests/e2e/test_rc_column_e2e.py`)

* **시나리오 1 (초기 로딩 및 렌더링)**:
  - 브라우저로 사이트 접속 $\rightarrow$ 1열 좌측 트리에서 `RC > RC 기둥` 클릭 $\rightarrow$ 2열 Left-Sub(부재목록+입력폼), 3열 Center 캔버스(단면도 및 P-M 다이어그램), 4열 Right 순백색 계산서가 모두 로딩되는지 확인.
  - 브라우저 콘솔 오류 로그 0건 확인.
* **시나리오 2 (파라메트릭 변경 동기화)**:
  - 기둥 폭 $B$를 500에서 600으로 변경 $\rightarrow$ 3열 단면도 폭이 즉시 600으로 갱신되는지 확인 $\rightarrow$ P-M 곡선 강도가 증가하는지 확인 $\rightarrow$ 4열 계산서의 $A_g$가 $300,000\text{ mm}^2$로 재렌더링되는지 확인.
* **시나리오 3 (철근 배근 모달 인터랙션)**:
  - 배근 탭에서 `...` 버튼 클릭 $\rightarrow$ 철근 상세 모달(`modal_manager.js`) 표시 $\rightarrow$ 크로스타이 옵션 변경 후 확인 $\rightarrow$ 3열 캔버스에 다이아몬드 대근 즉시 반영 확인.
* **시나리오 4 (다중 부재 매니저 연동)**:
  - Pane 1에서 `[+ 추가]` 클릭 $\rightarrow$ 신규 기둥(`1F-C2`) 생성 확인 $\rightarrow$ 부재 전환 시 폼, 캔버스, 계산서의 즉각 동기화($\le 50\text{ms}$) 확인.
* **시나리오 5 (A4 인쇄 및 옵션 전환)**:
  - 계산서 상단의 `요약 / 상세` 라디오 토글 및 `[입력 데이터 상세 포함]` 체크박스 토글 확인.
  - 인쇄 버튼 클릭 시 `@media print` 스타일 적용 및 상시 순백색(`#ffffff`) 레이아웃 무결성 확인.

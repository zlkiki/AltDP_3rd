## 2. 4-Pane 워크스페이스 100ms 실시간 상호작용 검증 시나리오

철골 주각부 모듈 선택 시 4개 열(Pane 1~4)이 유기적으로 동기화되는 E2E 동작 시나리오입니다:

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│ [4-Pane 워크스페이스 실시간 상호작용 흐름도]                                                      │
├─────────────────┬─────────────────┬───────────────────────────────┬──────────────────────────────┤
│ [Pane 1: 매니저]│ [Pane 2: 입력폼] │ [Pane 3: 그래픽 뷰포트]       │ [Pane 4: A4 구조계산서]      │
│  1F-BP1 클릭   ──► 4대 서브탭 로드 ─► 입면(응력도) & 평면(볼트) 렌더─► 8단계 KaTeX 전개식 즉각 표출  │
│  요약 행 선택   │ 치수/하중 변경  │ 100ms 이내 실시간 리드로우    │ 100ms 이내 DCR/판정 동시 갱신│
└─────────────────┴─────────────────┴───────────────────────────────┴──────────────────────────────┘
```

### 2.1. 시나리오 1: 기둥 형강 단면 변경 및 캔버스 즉시 동기화
* **사용자 조작**: Tab 1에서 기둥 규격을 `H-400x400x13x21`에서 `H-428x407x20x35`로 변경.
* **실시간 캔버스 동기화 (100ms 이내)**:
  - Pane 3 평면도: 기둥 플랜지 및 웨브 두께, 필릿 라운딩 형상이 즉시 확대 렌더링.
  - Pane 3 입면도: 기둥 폭 확대 반영.
  - **계산서는 불필요한 과부하 방지를 위해 대기**.

### 2.2. 시나리오 2: `[⚡ 검토 (Check)]` 버튼 클릭에 따른 KDS 계산서 및 DCR 갱신
* **사용자 조작**: Tab 1에서 플레이트 두께를 `35 mm`에서 `55 mm`로 증대 후 `[⚡ 검토]` 클릭.
* **KDS 해석 및 계산서 갱신 (100ms 이내)**:
  - Pane 3 입면도: 베이스플레이트 단면 두께 그래픽이 시각적으로 두꺼워지고 지압응력 재분포.
  - Pane 4 순백색 A4 계산서: 플레이트 휨 DCR이 $(53.1/35)^2 = 2.30$ (NG, 적색)에서 $(53.1/55)^2 = 0.93$ (O.K, 녹색)으로 즉각 반전 전개.
  - Pane 1 요약 그리드: 플레이트 DCR 및 종합 판정 O.K 즉시 반영.

### 2.3. 시나리오 3: 앵커볼트 수량 및 매립깊이($h_{ef}$) 변경 후 검토
* **사용자 조작**: Tab 3에서 앵커 규격을 `4-M24`에서 `8-M24`로 확장하고 $h_{ef}$를 `300 mm`에서 `450 mm`로 증대 후 `[⚡ 검토]` 클릭.
* **실시간 동기화 (100ms 이내)**:
  - Pane 3 평면도: 8개 앵커볼트 홀 위치와 피치 간격 치수선이 즉시 리드로우.
  - Pane 3 입면도: 앵커 매립 샤프트선 및 지압판 심볼이 하부로 깊게 연장 렌더링.
  - Pane 4 계산서: 콘크리트 브레이크아웃 강도 $\phi N_{cb}$ 및 전단강도 $\phi V_n$ 증대, 앵커 DCR 하향 안정화.

### 2.4. 시나리오 4: `[✨ 자동설계]` 파이프라인 및 편심 모멘트 지압 다이어그램 전환
* **사용자 조작**: Tab 4에서 휨모멘트 $M_u$를 `180 kN·m` (대편심)으로 입력 후 `[✨ 자동설계]` 클릭.
* **자동설계 동작**: 최적 소요 플레이트 두께 $t_p=55\text{mm}$ 및 소요 앵커볼트 규격을 자동 산출하여 폼에 주입 및 메모리 동기화.
* **검토 결과 동기화**:
  - Pane 3 입면도: 하부 지압 다이어그램이 한쪽 끝 $Y_c$ 구간 집중 삼각형으로 변환되고, 반대편 앵커볼트에 상향 인장 화살표($T_u\text{ kN}$)가 동적 생성.
  - Pane 4 계산서: `대편심(앵커 인장)`으로 분기 전환되며 2차방정식 $Y_c$ 유도 수식과 앵커 인장 검토 블록 활성화.

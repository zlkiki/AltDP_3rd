## 2. 4-Pane 올인원 워크스페이스 100ms 실시간 동기화 파이프라인

├────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                        │
│   [Left-Sub Pane 2] 사용자 파라미터 입력 (두께, 길이, 배근, 하중)                      │
│            │                                                                           │
│            ▼                                                                           │

│            │                                                                           │

## 4. E2E 통합 검증 시나리오 (End-to-End Scenarios)

### 4.1. 시나리오 1: 모듈 마운트 및 기본 상태 무결성
* **동작**:
  1. 사이드바 탐색기에서 `RC 콘크리트 > 전단벽` 클릭.
* **검증 기준**:
  - Pane 1에 기본 부재 `1F-W1` 등록 및 그리드 정상 표출.
  - Pane 2에 4대 서브탭(`단면/재료`, `철근배근`, `부재력/전단`, `내진/경계요소`) 정상 마운트.
  - Pane 3 상단에 벽체 입면도, 하단에 벽체 평단면도(복배근 D13@200) 정밀 렌더링.
  - Pane 4에 순백색 A4 8단계 KaTeX 계산서 즉시 출력.
  - 브라우저 개발자 도구 콘솔 에러 0건.

### 4.2. 시나리오 2: 파라메트릭 제원 변경 및 실시간 동기화
* **동작**:
  1. Tab 1에서 벽체 두께 $t_w$를 `300 mm`에서 `350 mm`로 수정.
  2. Tab 2에서 수평 전단근 규격을 `D13`에서 `D16`으로 변경.
  3. `[⚡ 검토 (Check)]` 버튼 클릭.
* **검증 기준**:
  - 100ms 이내에 하단 단면도의 두께 및 배근선이 굵어지며 실시간 재렌더링.
  - 백엔드 검토 API 응답 수신 후 전단 강도 $\phi V_n$이 증가하고 DCR이 감소 반영.
  - 계산서 제4장의 $V_s$ 및 $\phi V_n$ 계산식이 새 치수와 철근 면적($A_v$)으로 자동 재전개.

### 4.3. 시나리오 3: 내진 특수경계요소(SBE) 분기 및 모달 연동
* **동작**:
  1. Tab 4에서 설계변위 $\delta_u$를 `30 mm`에서 `60 mm`로 2배 증가.
  2. `[ 내진/특수경계요소 상세... ]` 버튼 클릭하여 `IDD_RCS_WALL_SEISMIC_DLG` 모달 오픈.
* **검증 기준**:
  - 한계 중립축 깊이 $c_{limit}$이 절반으로 감소하여 $c \ge c_{limit}$ 조건을 만족함에 따라 모달 내 판정이 `[특수경계요소 설치 대상 (SBE REQUIRED)]`로 자동 전환.
  - 모달에서 구속 길이 $l_c$ 확인 후 적용 클릭 시, 하단 뷰포트에 특수경계요소 주황색 빗금 해치 및 횡구속 띠철근/크로스타이 심볼이 즉시 렌더링.
  - 계산서 제5장의 판정 문구가 `특수경계요소 설치 대상 [SBE REQUIRED]`로 변경되며 $A_{sh}$ 적합성 검토식이 전개.

## 2. [Left Sidebar] 스마트 계층형 모듈 탐색기 (`#sidebar-nav`)

DOCS 07 제3절의 스마트 사이드바를 기반으로, 번잡한 상단 검색창/칩을 덜어내고 사이드바 내에 **초고접근성 3중 필터 네비게이션**을 구축합니다.

### 2.1. 큰 그룹보기(Category Pills) 및 전체보기 탭 필터
* **[전체보기 (ALL)]**: 61종 전체 모듈 전개.
* **[즐겨찾기 (⭐ Favorites)]**: 사용자가 즐겨찾기 등록한 모듈 및 활성 부재만 최상단 집중 표시.
* **[RC 콘크리트]**: 보, 기둥, 전단벽, 슬래브, 기초, 옹벽, 지하외벽, 앵커볼트, 코벨/브라켓.
* **[STEEL 강구조]**: 철골보, 철골기둥, 가새, 트러스, 크레인거더, 접합부 5종, 베이스플레이트.
* **[SRC / PC]**: SRC 기둥/보, CFT 기둥, 프리캐스트 보/슬래브, 더블티, 할로우코어.
* **[ALU 알루미늄]**: 알루미늄 보/기둥, 커튼월 멀리온, 루버 프레임.
* **[RFM 보강]**: CFRP 탄소섬유판/시트 보강, 강판 접착 보강, 콘크리트 단면증설.
* **[기초 / 특수]**: 독립/복합/줄기초, 말뚝기초, 평판 FEM 매트기초.

### 2.2. 즐겨찾기(Favorites ⭐) 상시 고정 시스템
* 각 모듈 및 부재명 우측에 별표 아이콘(`☆`/`★`) 제공.
* 클릭 시 `localStorage`에 영속화되며 사이드바 최상단 `[⭐ 즐겨찾기]` 그룹에 상시 고정되어 실무 빈출 부재(RC보, 기둥, H형강보 등)로 1클릭 즉시 이동.

### 2.3. 3단계 계층 WorkTree 및 DCR 2단계(OK/NG) 글자 표기
* **Level 1 (대분류)** $\rightarrow$ **Level 2 (단위 모듈 & 등록 부재 수)** $\rightarrow$ **Level 3 (개별 등록 부재 `1F-B1` 등)**.
* **DCR 상태 2단계 텍스트 표기 (칩/배경색 제거, 폰트 컬러로만 표기)**:
  - **OK (`DCR ≤ 1.000`)**: **녹색 글자 (`OK`)**로만 표기.
  - **NG (`DCR > 1.000`)**: **빨간색 글자 (`NG`)**로만 표기. 클릭 시 해당 부재로 즉시 전환되고 4열 계산서의 불합격 수식 위치로 자동 스크롤.
* **스마트 자동 숨김 및 고정핀 (📌)**: 마우스 이탈 시 3초 후 슬라이드 수축 (`Ctrl + B` 단축키 토글 지원).

## 3. [Left-Sub Pane] 다중 부재 매니저 (Pane 1) & 사용자 입력부 (Pane 2)

DOCS 07 제4.1절 및 제4.2절에 명시된 좌측 2단 적층 영역입니다. 상단의 부재 목록 테이블과 하단의 파라메트릭 입력폼이 상하 수직 리사이저(`resizer-left-v`)로 연결됩니다.

### 3.1. Pane 1: 다중 부재 매니저 (`#pane-member-list`)
* **위치**: Left-Sub 상단 (높이: 80px ~ 400px 가변 조절).
* **컴포넌트**: `member_manager.js`
* **주요 기능**:
  - **부재 인스턴스 CRUD**: `[+ 추가]`, `[복제]`, `[삭제]` 툴바 버튼.
  - **인라인 부재명 변경**: 더블클릭으로 `1F-B1`, `Roof-G2` 등 인라인 편집.
  - **실시간 요약 스프레드시트 테이블**:
    | 부재명 | 단면 치수 ($b \times h$) | 주요 배근 / 형강 규격 | 소요력 ($M_u, V_u$) | DCR 상태 (글자 표기) |
    |:---:|:---:|:---:|:---:|:---:|
    | **1F-B1** | $400 \times 600$ | 상 4-D25, 하 4-D25 | $210 \text{ kN}\cdot\text{m}$ | **0.807 OK** (녹색 글자) |
    | **1F-B2** | $500 \times 700$ | 상 6-D25, 하 6-D25 | $450 \text{ kN}\cdot\text{m}$ | **1.052 NG** (빨간색 글자) |
  - 부재 행 클릭 시 0.01초 내 해당 부재의 입력폼, 그래픽 뷰, 계산서가 즉각 활성화.

### 3.2. Pane 2: 파라메트릭 사용자 입력부 (`#pane-input-form`)
* **위치**: Left-Sub 하단.
* **컴포넌트**: `form_generator.js`, `form_combobox.js`
* **2단 적층형 헤더**: 1행 `⚙️ 사용자 입력부 (Input) [1F-B1]` + 2행 모듈 경로 배너 (`RC › 보 (Beam) › 직사각형 보`).
* **부재 고유 4대 서브탭 구조**:
  1. **[단면 / 재료 탭]**: 단면 치수, KS 강종(`fck, fy, fys, SM355` 등 표준 콤보박스), 피복두께, Section DB 선택.
  2. **[배근 / 상세 탭]**: 주철근 직경/단수/간격, 스터럽/대근 간격, 볼트 직경/배열/수량, 긴장재 가닥수.
  3. **[설계 하중 탭]**: 계수 축력($P_u$), 모멘트($M_u$), 전단력($V_u$), KDS 하중조합 생성기 연동.
  4. **[설계 옵션 탭]**: 처짐/균열 사용성 환경, 내진설계 범주(SMF/IMF), 장주 비지지길이($kL/r$).
* **원본 1:1 서브 대화창(`...`) 모달 시스템 (`ModalManager`)**:
  - `IDD_RCS_BEAM_BEFF_DLG`: T형/L형 플랜지 유효폭($b_{eff}$) 자동 계산 모달.
  - `IDD_RCS_COLUMN_SWAY_DLG`: 장주 모멘트확대계수($\delta_{ns}, \delta_s$) 산정 모달.
  - `IDD_STEEL_SECTION_DB_DLG`: KS H형강, 각형강관 단면성능치 브라우저 모달.
  - `IDD_LOAD_COMBINATION_DLG`: KDS 41 10 15 하중조합 생성 모달.
* **3버튼 통합 액션 툴바**:
  - **[💾 적용 (Apply)]**: 폼 수정값을 `ProjectStore`에 즉시 저장하고 중앙 그래픽 및 부재 목록 갱신.
  - **[⚡ 검토 (Check)]**: 적용 선행 후 KDS 엔진을 호출하여 우측 계산서 및 DCR 상태 글자(OK/NG) 갱신.
  - **[✨ 설계 (Design)]**: 적용 선행 후 `auto_designer.js`를 구동하여 최적 배근/단면 자동 산출.

## 4. [Center Pane] 세로 적층형 다중 뷰포트 그래픽 정보부 (`#pane-graphic-view`)

DOCS 07 제4.3절의 대화형 캔버스를 계승하되, **세로로 긴 종방향 뷰포트 특성**을 극대화하여 **상/하 2단 세로 적층형 다중 뷰포트 (Vertical Multi-Card Layout)**로 구성하고, RC뿐 아니라 철골, PC, 보강, 접합부 등 전 부재군의 역학 시각화를 전면 반영합니다.

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│ Center Graphic Viewport (세로 적층형 2단 다중 뷰포트)                                             │
├──────────────────────────────────────────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────────────────────────────────────────────────────┐ │
│ │ [상단 뷰포트: 형상 및 단면 상세 (Geometry & Reinforcement)]            [Fit] [Zoom] [Dim 켜기]│ │
│ │  • RC: 2D 단면 배근도 (외곽선 해칭, 피복선, 135° 후크 스터럽, 다단배근 솔리드 점, 치수선)  │ │
│ │  • Steel: KS H형강 단면 치수(B, H, tf, tw, r) 및 조밀/비조밀 색상 코딩                        │ │
│ │  • 접합부: 2D CAD 평면 볼트 배열도 (게이지, 피치, 연단거리 치수선, 용접 비드)                 │ │
│ │  • 기초: 기초판 평면도 (B x L), 기둥 위치, 말뚝(Pile) 그리드, 1/2방향 위험단면선            │ │
│ └──────────────────────────────────────────────────────────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────────────────────────────────────────────────────────┐ │
│ │ [하단 뷰포트: 공학 역학 다이어그램 (Mechanics & Interaction Diagram)]  [Fit] [Zoom] [DCR 바]  │ │
│ │  • 기둥: P-M 상관도 곡선 (Pn-Mn 및 φPn-φMn 곡선, 계수하중 Pu-Mu 타점 십자선 마커, 3D 뷰)   │ │
│ │  • 보: 종단면 배근 프로파일 및 계수 휨모멘트(Mu)/전단력(Vu) 포락 다이어그램                  │ │
│ │  • 기초: 지반 접지압 분포도 (편심하중에 따른 사다리꼴/삼각형 q_min ~ q_max 다이어그램)       │ │
│ │  • 접합부: 정면/측면 입면 단면 및 앵커볼트 인장 콘(Cone)/전단 파열면 상세                     │ │
│ │  • 보수보강: 보강 전 vs 보강 후 내력 증분 비교 차트 (CFRP/강판 부착 효과)                     │ │
│ └──────────────────────────────────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 4.1. 전 부재군 그래픽 특성화 매트릭스
1. **RC 보 / 기둥**:
   - 135° 내진 갈고리(Hook) 절곡 스터럽 ($r=2d_b$).
   - 상/하부 1단 및 2단 주철근 순간격(25mm) 검토 렌더링.
   - 기둥 P-M 상관곡선(설계곡선 vs 공칭곡선) 및 계수하중 타점 마커.
2. **철골 보 / 기둥**:
   - KS H형강 및 각형강관 단면 형상, 필렛 라운딩.
   - 판폭두께비 조밀/비조밀/세장 단면 영역 색상 하이라이트.
   - 횡비틀림좌굴(LTB) 모멘트 구배 다이어그램 ($C_b$) 및 비지지길이($L_b$) 구간도.
3. **철골 접합부 / 베이스플레이트**:
   - 2D CAD 평면도: 볼트 구멍, 볼트 게이지/피치/연단거리 치수선, 플레이트 외곽선.
   - 입면도: 모르타르 두께, 기초 콘크리트 지압선, 앵커볼트 인장 콘(Cone) 파열선.
4. **RC 슬래브 / 기초 / 옹벽**:
   - 기초판 평면 배근망 및 말뚝 배치 그리드.
   - 편심 하중에 따른 지반 접지압 사다리꼴/삼각형 분포도 ($q_{min} \sim q_{max}$).
   - 1방향 전단($d$) 및 2방향 뚫림전단($d/2$) 위험단면 적색 점선 표출.
5. **PC / PSC 및 보수보강(RFM)**:
   - 프리캐스트 단면(더블티, 할로우코어) 및 긴장재(Strand) 중심선 배치도.
   - CFRP 탄소섬유판/강판 접착 위치 및 보강 전/후 내력 증분 비교 막대 차트.

### 4.2. 대화형 인터랙션
* 상단/하단 카드별 독립 줌(Zoom)·팬(Pan), 뷰포트 맞춤(`[Fit]`).
* 철근, 볼트, 텐던 마우스 오버 시 직경, 배근 간격, 단면적 호버 툴팁 표출.

# 요구사항 20-3: 사용자 입력부 4대 서브 탭 및 서브 대화창(Modal) 시스템 구축

## 1. 개요 및 목적
Midas Design+ 원본 다이얼로그(`DLG_*.ini`)의 파라메트릭 인풋 시스템을 웹 3열 사용자 입력부에 100% 동일하게 구현합니다. 복잡한 파라미터를 **4대 내부 서브 탭([단면/재료], [철근배근], [설계하중], [검토옵션])**으로 분류하고, 원본에서 `...` 버튼 클릭 시 팝업되던 서브 대화창을 **웹 모달 시스템(`ModalManager`)**으로 완벽히 구축합니다.

---

## 2. 세부 개발 사양

### 2.1. 3열 입력부 4대 서브 탭 폼 프레임워크
* **서브 탭 네비게이션**:
  - `[단면 및 재료]`: 부재 기하 치수 ($b, h, t_w, t_f$), 콘크리트 강도 ($f_{ck}$), 주철근 강도 ($f_y$), 전단철근 강도 ($f_{ys}$), 탄성계수.
  - `[철근 배근]`: 상부/하부 주철근 단수, 직경, 개수, 전단 스터럽 직경/간격, 표피철근.
  - `[하중 및 부재력]`: 계수 모멘트 ($M_u$), 계수 전단력 ($V_u$), 축력 ($P_u$), 비틀림 모멘트 ($T_u$).
  - `[검토 옵션]`: 내진등급(특수/중간/보통), 환경조건(건조/기타), 허용처짐 기준($L/240, L/480$).
* **실시간 변경 이벤트 브로드캐스팅**:
  - 입력값 변경 시 0.05초 디바운스로 이벤트 버스(`EventBus`)를 통해 2열 캔버스와 4열 계산서에 즉시 반영.
  - P/S/M 모드 구분 없이 통합 파라메트릭 폼으로 직관적 동작.

### 2.2. 원본 서브 대화창(Modal Popup) 시스템 (`ModalManager`)
원본 다이얼로그 ID와 1:1 매핑되는 핵심 공통 모달 컴포넌트를 구축합니다:

1. **설계 하중조합 대화창 (`IDD_RCS_DESIGN_LOAD`)**:
   - 하중 탭의 `...` 버튼 클릭 시 팝업.
   - 고정하중($D$), 활하중($L$), 지진하중($E$), 풍하중($W$) 성분별 부재력 입력.
   - KDS 자동 하중조합($1.4D$, $1.2D+1.6L$, $1.2D+1.0L+1.0E$ 등) 생성 및 지배(Governing) 하중조합 자동 산출.
2. **KS 철골 형강 DB 선택기 (`IDD_STL_BEAMCOL_SMODE_INPUT_SECT1_DLG`)**:
   - 철골 단면 선택 시 팝업.
   - H형강, 각형강관, 원형강관, 찬넬, 앵글 규격 검색/필터링 및 단면 성질($A, I_x, I_y, Z_x, S_x, r_x$) 자동 바인딩.
3. **단면 상세 설정 대화창 (`IDD_RCS_BEAM_SECT_DLG`)**:
   - T형 보 플랜지 유효폭($b_e$), 슬래브 두께($h_f$), 비대칭 플랜지 치수 입력.
4. **처짐 및 균열 상세 검토 대화창 (`IDD_RCS_DEFL_DLG`)**:
   - 즉시 처짐, 장기 처짐 시간의존계수($\xi$), 균열 환산단면 2차모멘트($I_{cr}$) 상세 설정.
5. **베이스플레이트 및 고력볼트 상세 대화창 (`IDD_STL_USBP_PLAT_DLG`, `IDD_STL_BOLTCONN_SMODE_INPUT_SECT2_DLG`)**:
   - 베이스플레이트 가로/세로/두께, 앵커볼트 배열 피치/게이지, 볼트 전단면수 상세 설정.

## 3. 구현 대상 파일 목록
* `src/web/static/js/core/modal_manager.js`: 웹 모달 팝업 생명주기 관리자
* `src/web/static/js/core/common_dialogs.js`: 하중조합, 형강 DB, 처짐/균열 공통 모달 렌더러
* `src/web/static/js/core/form_builder.js`: 4대 서브 탭 및 인풋 필드 동적 생성 빌더
* `src/web/static/css/modal.css`: 원본 감성의 엔지니어링 모달 다이얼로그 스타일링

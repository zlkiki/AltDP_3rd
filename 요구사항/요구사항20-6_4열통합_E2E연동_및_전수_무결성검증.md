# 요구사항 20-6: 4열 통합 E2E 연동, 반응형 레이아웃 검증 및 Pytest 전수 무결성 검증

## 1. 개요 및 목적
구축된 트리메뉴, 모듈 디스패처, VDraw 캔버스 엔진, 4대 서브 탭 및 서브 모달 폼, 원본 5대 장구분 계산서 뷰어를 통합 결합하여 **엔드투엔드(E2E) 상호작용 무결성**을 입증합니다. 브라우저 콘솔 에러 0건, 반응형 레이아웃 최적화 및 3대 도메인 Pytest 자동화 테스트(`tests/engine/`, `tests/api/`, `tests/report/`) 100% 통과를 통해 요구사항 20을 최종 완수합니다.

---

## 2. 세부 검증 및 최적화 사양

### 2.1. 4열 인터랙션 E2E 통합 검증
* **트리메뉴 ➔ 3열 ➔ 2열 ➔ 4열 캐스케이드 연동**:
  - 트리메뉴에서 부재 변경 시 0.05초 이내에 캔버스(2열), 입력폼(3열), 계산서(4열)가 동시 전환되는지 검증.
* **3열 파라메트릭 변경 ➔ 실시간 반영 속도**:
  - 단면 크기, 철근 배근, 설계 하중 수정 시 캔버스 2D 그래픽과 계산서 DCR이 60fps로 매끄럽게 동기화되는지 검증.
* **서브 대화창(모달) 상호작용 검증**:
  - 하중조합 모달, KS 형강 DB 선택기, 처짐/균열 상세 모달에서 데이터 변경 후 적용 시 메인 폼과 엔진에 정확히 전달되는지 확인.

### 2.2. 브라우저 반응형 레이아웃 및 콘솔 무결성 검증
* **화면 분할 비율 최적화**:
  - 1열(트리: 18%), 2열(캔버스: 32%), 3열(입력폼: 25%), 4열(계산서: 25%) 비율 및 최소 해상도(1440px ~ 4K) 지원.
* **브라우저 콘솔 무결성**:
  - 모든 부재 전환, 모달 팝업, 계산서 출력 시 자바스크립트 오류 및 네트워크 에러 0건 달성.

### 2.3. 도메인별 3대 Pytest 및 0.1% 오차 무결성 검증
* **설계 엔진 테스트**: `pytest tests/engine/` (전 부재 KDS 수식 및 내력비 0.1% 오차 무결성 검증)
* **REST API 라우트 테스트**: `pytest tests/api/` (엔드포인트 입출력 스키마 무결성)
* **구조계산서 테스트**: `pytest tests/report/` (HTML/PDF 렌더링 무결성)
* **전체 통합 검증**: `pytest` 100% 통과

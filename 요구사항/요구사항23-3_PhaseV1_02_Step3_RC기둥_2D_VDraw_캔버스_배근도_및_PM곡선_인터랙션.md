## 2. 2D 캔버스 듀얼 뷰포트(Dual Viewport) 분할 구조

RC 기둥 캔버스는 상/하 2개의 전문 뷰포트로 분할 렌더링됩니다:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [캔버스 뷰포트 A: 기둥 횡단면도 (Cross-Section & Rebar Layout)]                         │
│  - 콘크리트 외곽 사각/원형 윤곽선 (B x H 또는 D)                                      │
│  - 외곽 폐합 띠철근 (135° 절곡 갈고리) 및 내부 크로스타이/다이아몬드 대근                │
│  - 원형 솔리드 주철근 심볼 (정확한 기하 좌표 배치)                                     │
│  - 치수선 (치수 보조선, 화살표, 수치 레이블) 및 철근 태그 지시선 (Leader Line)        │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ [캔버스 뷰포트 B: 200 파이버 KDS P-M 상관곡선 (Interactive P-M Diagram)]               │
│  - 공칭강도 곡선 (Pn - Mn) 점선 및 설계강도 곡선 (phi_Pn - phi_Mn) 실선                │
│  - 최대 설계축강도 수평 한계선 (phi_Pn,max)                                            │
│  - 균형파괴점 (Balanced Point B), 순수 휨점 (M0), 순수 인장점 (P_tens) 마커            │
│  - 계수 설계하중점 (Pu, Mux, Muy) 플롯 및 안전/초과 시각화                              │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 3. 세부 그래픽스 렌더링 알고리즘 명세

### 3.1. 뷰포트 A: 기둥 단면 및 배근도 렌더링 (`renderColumnCrossSection`)
1. **월드 좌표계 변환 및 오토핏 (Auto-Fit)**:
   - 기둥 크기($B, H$)에 맞춰 캔버스 중앙에 최대 여백(25%)을 확보하며 스케일링 ($scale = \min(\frac{W_{vp} \times 0.75}{B}, \frac{H_{vp} \times 0.75}{H})$).
2. **콘크리트 단면 그리기**:
   - 사각 기둥: `ctx.strokeRect(-w/2, -h/2, w, h)`, 콘크리트 해치/배경색 `#f8fafc`.
   - 원형 기둥: `ctx.arc(0, 0, r, 0, 2*Math.PI)`, 은은한 림 라이트 효과.
3. **폐합 띠철근 (Outer Tie/Stirrup) 렌더링**:
   - 피복두께 $c_v$만큼 안쪽으로 옵셋된 사각형 패스.
   - 네 모서리 모따기 라운딩(곡률 반경 $r_{bend} = 2 d_{tie}$).
   - 한쪽 모서리에 135° 표준 내진 갈고리(Hook) 연장선 렌더링.
4. **내부 보강 띠철근 (Cross-Tie / Inner Diamond Tie)**:
   - 다리수($Legs_X, Legs_Y$)에 맞춰 중간 주철근을 감싸는 수평/수직 크로스타이 렌더링.
5. **주철근 솔리드 심볼 렌더링**:
   - 코너 4개 주철근: 띠철근 굴곡부 내측에 안착되도록 정밀 좌표 산정 ($(\pm(B/2 - c_v - d_{tie} - d_b/2), \pm(H/2 - c_v - d_{tie} - d_b/2))$).
   - 변별 중간 철근: 균등 분할 피치 계산 후 원형 솔리드(`#1e293b` 또는 강도별 컬러) 채우기 및 외곽선 스트로크.
6. **치수선 및 배근 지시선 태그 (Dimension & Tags)**:
   - 기둥 상단/좌측에 치수선($B, H$), 외곽 보조선, 치수 텍스트 표시.
   - 대표 주철근에 지시선(Leader Line)을 인출하여 `12-D25 (SD400)` 형태의 정밀 태그 렌더링.
   - 띠철근에 지시선 인출하여 `D10 @300` 태그 표시.

### 3.2. 뷰포트 B: P-M 상관곡선 차트 렌더링 (`renderPMDiagram`)
1. **좌표축 및 눈금 (Axes & Grid)**:
   - 가로축: 휨모멘트 $M$ (kN·m), 세로축: 축력 $P$ (kN, 압축 상향, 인장 하향).
   - 그리드 라인 점선 및 단위 표기.
2. **KDS 200 파이버 곡선 플롯**:
   - 공칭강도 곡선: 점선 회색 (`#94a3b8`, linewidth 1.5).
   - 설계강도 곡선 ($\phi P_n - \phi M_n$): 굵은 실선 청색 (`#2563eb`, linewidth 2.5).
   - 최대 압축축하중 수평 컷오프선: $\phi P_{n,max}$ 주황색 쇄선 (`#f59e0b`).
3. **핵심 특성점 마커**:
   - $P_0$ (순수 압축점), $B$ (균형 파괴점, $\epsilon_t = \epsilon_y$), $M_0$ (순수 휨점), $T_{max}$ (순수 인장점)에 원형 마커 및 레이블 표시.
4. **설계하중점 플롯 및 안전성 시각화**:
   - 확대 계수하중점 $(M_{cx}, P_u)$ 플롯.
   - DCR $\le 1.000$ (곡선 내부): 녹색 원형 마커 (`#10b981`) 및 "OK (DCR = 0.782)" 뱃지.
   - DCR $> 1.000$ (곡선 외부): 적색 점멸 마커 (`#ef4444`) 및 "NG (DCR = 1.145)" 뱃지.

## 4. 캔버스 인터랙션 및 이벤트 처리 규약

1. **마우스 휠 줌 & 드래그 팬**:

## 2. 4-Pane 워크스페이스 실시간 3-View 동기화 파이프라인

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│ AltDP_3rd RC 보 4-Pane 워크스페이스 실시간 동기화 아키텍처 (ProjectStore 기반)                  │
├─────────────────┬───────────────────────────────┬───────────────────────┬───────────────────────┤
│ [1열: 사이드바] │ [2열: Left-Sub (부재/폼)]     │ [3열: Center 그래픽]  │ [4열: Right 계산서]   │
│  RC > 보 선택   │  • Pane 1: 다중 부재 매니저   │  • 상단: 종단면/부재력│  - 5대 장구분 계산서  │
│  (Online 활성)  │  • Pane 2: 4대 서브탭 입력폼  │  • 하단: 3대 횡단면도 │  - 8단계 KaTeX 전개   │
│                 │    - 단면/재료 (KS 콤보박스)  │  - 135° 갈고리 스터럽 │  - 순백색 A4 프리뷰   │
│                 │    - 철근배근 (모달 연동)     │  - 철근태그/치수선    │  - O.K / N.G 상태     │
│                 │    - 부재력 / 사용성 처짐균열 │  - 휠 줌/팬/Fit/호버  │  - 인쇄/PDF/Excel     │
└─────────────────┴───────────────────────────────┴───────────────────────┴───────────────────────┘
                                ▲                         ▲                        ▲
                                │ (Input Event)           │                        │
                                └────── [ProjectStore] ───┴────────────────────────┘
                                      (State Update <= 50ms)
```

### 2.1. 인터랙티브 반응 속도 기준
- 2열 Left-Sub 입력폼에서 보 단면 치수($b_w, h$), 주철근 호칭경 및 개수, 스터럽 간격 등을 수정할 때:
  1. `ProjectStore` 상태 갱신: $\le 10\text{ ms}$
  2. 3열 캔버스 종단면 및 3대 횡단면 치수 리드로우: $\le 30\text{ ms}$
  - **폼 입력 시에는 캔버스/치수선만 즉시 동기화하고 계산서는 불필요한 과부하를 막기 위해 대기**
- **[⚡ 검토] 버튼 클릭 시**:
  1. 파이썬 백엔드 KDS 보 해석 및 검토: $\le 40\text{ ms}$
  2. 4열 A4 계산서 KaTeX 수식 렌더링 및 DCR 갱신: $\le 50\text{ ms}$
  - **총 검토 소요 시간 $\le 100\text{ ms}$**로 끊김 없는 인터랙티브 설계 환경 확보.

## 4. E2E 통합 테스트 시나리오 및 검증 (`tests/e2e/test_rc_beam_e2e.py`)

1. **시나리오 1: 사이드바 네비게이션 및 모듈 마운트**:
   - 1열 사이드바에서 `RC 보` 클릭 시 2열 Left-Sub에 4대 서브탭 폼이 마운트되고, 3열에 세로 적층 캔버스 뷰포트가 생성되며, 4열에 계산서가 로드되는지 검증.
2. **시나리오 2: 파라메트릭 입력 및 3대 액션 버튼 파이프라인 검증**:
   - 폼에서 폭 $b_w$를 400에서 500으로 변경 시 3열 캔버스 치수선이 500으로 즉시 갱신되되, 4열 계산서는 갱신되지 않음 확인.
   - `[⚡ 검토]` 버튼 클릭 시에만 KDS 검토가 실행되어 4열 계산서 제1장 및 휨모멘트 강도가 $b_w=500$으로 재계산되고 DCR이 갱신되는지 확인.
   - `[✨ 자동설계]` 버튼 클릭 시 현재 하중에 적합한 최적 철근 배근이 폼에 자동 입력되는지 확인.
3. **시나리오 3: 2D 캔버스 인터랙션**:
   - 캔버스 휠 줌, 드래그 팬 시 에러 없이 변환 행렬이 적용되는지 검증.
4. **시나리오 4: A4 계산서 인쇄 프리뷰 및 테마 전환**:
   - 다크/라이트 테마 전환 시 폼/테이블 배경 및 글자색 반전 무결성 확인.
   - 인쇄 버튼 클릭 시 미디어 쿼리(`@media print`)가 적용된 순백색(`#ffffff`) A4 프리뷰 윈도우가 정상 호출되는지 검증.

4. 상세 설계 및 한계상태 검토 과정 (Step-by-Step)
4.1 휨모멘트 설계강도 검토 (KDS 14 20 20) {{ flexure_check.dcr | dcr_badge | safe }}
1. 등가응력블록 깊이 ($a$): $$a = \frac{A_s f_y}{\alpha_1 f_{ck} b} = \frac{ {{ flexure_check.As | fmt_num(1) }} \times {{ material.fy | fmt_num(0) }} }{ 0.85 \times {{ material.fck | fmt_num(0) }} \times {{ section.b | fmt_num(0) }} } = {{ flexure_check.a | fmt_num(2) }} \, \text{mm}$$
2. 공칭/설계휨강도 ($\phi M_n$): $$\phi M_n = \phi A_s f_y \left(d - \frac{a}{2}\right) = {{ flexure_check.phi | default(0.85) | fmt_num(2) }} \times {{ flexure_check.As | fmt_num(1) }} \times {{ material.fy | fmt_num(0) }} \left({{ section.d | fmt_num(1) }} - \frac{ {{ flexure_check.a | fmt_num(2) }} }{2}\right) \times 10^{-6} = {{ flexure_check.phi_Mn | fmt_moment }}$$
3. 휨 DCR 및 판정: $$\text{DCR} = \frac{M_u}{\phi M_n} = \frac{ {{ loads.Mu | fmt_num(2) }} }{ {{ flexure_check.phi_Mn | fmt_num(2) }} } = \mathbf{ {{ flexure_check.dcr | fmt_dcr }} } \le 1.0 \quad \left( {% if flexure_check.dcr <= 1.0 %}\text{OK}{% else %}\text{NG}{% endif %} \right)$$
4.2 전단강도 설계검토 (KDS 14 20 22) {{ shear_check.dcr | dcr_badge | safe }}
1. 콘크리트 부담 전단 ($\phi V_c$): $$\phi V_c = \phi \frac{1}{6} \sqrt{f_{ck}} b_w d = 0.75 \times \frac{1}{6} \sqrt{ {{ material.fck | fmt_num(0) }} } \times {{ section.b | fmt_num(0) }} \times {{ section.d | fmt_num(1) }} \times 10^{-3} = {{ shear_check.phi_Vc | fmt_force }}$$
2. 스터럽 부담 전단 ($\phi V_s$): $$\phi V_s = \phi \frac{A_v f_{ys} d}{s} = 0.75 \times \frac{ {{ shear_check.Av | fmt_num(1) }} \times {{ material.fys | fmt_num(0) }} \times {{ section.d | fmt_num(1) }} }{ {{ shear_check.s | fmt_num(0) }} } \times 10^{-3} = {{ shear_check.phi_Vs | fmt_force }}$$
3. 전체 설계전단강도 ($\phi V_n$): $$\phi V_n = \phi V_c + \phi V_s = {{ shear_check.phi_Vn | fmt_force }} \ge V_u = {{ loads.Vu | fmt_force }} \implies \text{DCR} = \mathbf{ {{ shear_check.dcr | fmt_dcr }} } \quad \left( {% if shear_check.dcr <= 1.0 %}\text{OK}{% else %}\text{NG}{% endif %} \right)$$
